# 검증용 Python 예제

이 폴더는 완성된 웹 실행기를 제공하지 않습니다. Work가 공통 실습 기능을 구현한 뒤 실제 엔진과 화면에서 확인할 기준 예제입니다.

## 사용법

1. fixture_manifest.json의 목적·기대 결과를 읽으십시오.
2. 해당 런타임의 공통 실습 화면에 코드를 입력하십시오.
3. 전체 실행 결과와 한 줄씩 보기의 앞뒤 상태를 확인하십시오.
4. 04_ACCEPTANCE_CHECKLIST.csv의 연결 항목에 환경·실습 URL·증거를 기록하십시오.
5. CSV 예제에는 sales.csv를 실습 가상 파일 경로에 함께 제공하십시오.

25개 Python 파일 중 09는 의도적 실행 오류, 10은 의도적 문법 오류, 22는 의도적 무한 반복입니다. 22는 중지 가능한 격리 실행 환경에서만 실행하십시오. 모든 파일을 한꺼번에 무조건 실행하는 스크립트를 만들지 마십시오.

함수 프레임 예제는 실행기 검증용입니다. 특정 학년의 수업 범위에 함수·클래스를 추가하라는 지시가 아닙니다.

## 판정 주의점

- Turtle 좌표에는 정상적인 부동소수점 오차를 허용하십시오.
- set 순서·난수 값에 고정된 기대값을 강요하지 마십시오.
- input 프롬프트가 stdout과 별도 콘솔에 표시되는지는 UI 계약에 따르되 입력·결과·단계의 의미는 맞아야 합니다.
- pandas·Matplotlib·Turtle은 개발 PC의 Python 실행만으로 웹 기능 PASS를 선언하지 마십시오.
- 기존 네 가지 작품과 모든 수업 예제는 이 짧은 파일만으로 대체 검증할 수 없습니다. 최신 콘텐츠 원본도 전수 실행하십시오.
- 웹 미지원 API를 아무 동작 없이 성공시키는 stub으로 시험을 통과시키지 마십시오.

## 패키지 작성 시 검사와 사이트 시험의 구분

패키지 작성 과정에서는 파일 구문·기대 오류·일부 표준 Python 기준 결과·검증표 구조·ZIP 무결성만 확인합니다. 웹 기능 상태는 모든 예제에서 NOT_RUN입니다. 실제 사이트 검증 후에만 상태를 갱신하십시오.
