# SW 통합판 교사용 사용 방법
이 문서는 SW V2 통합 후보의 사용 방법입니다. 운영 게시 및 실계정 검증 상태는 ACCEPTANCE_RESULTS.md를 확인하세요.

1. [SW](https://sw.englishmath.kr/)에서 Google 로그인 후 본인 이름·계정과 고2 학급을 확인합니다. 신규 학생은 기존 고2 학급에 승인 요청을 하고, 담당 교사는 교사용 관리실에서 해당 요청을 승인합니다. 기존 승인과 교사 등록은 유지합니다.
2. 00 복습, 02 차시별 실습, 데이터 시각화, 04 복습 문제, 05 보고서 등 메뉴를 이동해도 같은 계정으로 이어집니다. 입력은 화면을 바꿔도 현재 탭의 초안으로 남습니다.
3. 변경 후 60초부터 자동 저장합니다. 여러 활동은 16초 간격으로 차례대로 처리합니다. ‘클라우드 저장 완료’가 표시되어야 서버 저장이 확인된 것입니다. 원하는 때 ‘계정에 저장’을 눌러도 됩니다. 읽기 전용 화면과 아바타에는 저장 버튼이 없습니다.
4. ‘내 학습 보관함’에서 종류별 ‘이어서 작성’을 누르면 해당 코드·답안·보고서·시각화 화면으로 열립니다. ‘최근 이력’은 최대 10개이며 명시적으로 선택한 이전본을 새 버전으로 저장합니다.
5. ‘선생님께 제출’은 계정 저장과 별도입니다. 제출할 활동을 확인한 뒤 보내세요. 담당 교사는 승인·진도·제출물만 확인하며 학생 개인 초안 본문은 읽지 않습니다.
6. 수업을 마칠 때 ‘이 PC 학습 마치기’ → ‘모두 저장 후 종료’를 누르고 로그인 전 상태를 확인합니다. 저장 실패 시 화면을 유지하거나 ‘초안 내려받기’로 보관하세요. 새로고침·탭 종료 후에는 공용 PC 보호를 위해 다시 로그인합니다.
7. 다른 PC에서 같은 Google 계정으로 로그인하면 서버에 저장된 활동을 복원합니다. 학생이 직접 선택한 CSV 파일은 업로드하지 않으므로 그 파일은 다시 선택해야 합니다. 교재의 가상 자료와 학생이 편집한 가상 자료는 해당 활동과 함께 복원합니다.
8. 분홍색 ‘AI 표정 아바타 실험실’은 추가 체험입니다. 카메라는 ‘카메라 시작’으로만 켭니다. 화면 이탈·학습 종료 때 카메라를 끄고 체험 코드·미션·표정 수치·영상은 저장하지 않습니다.
9. ‘새 파이썬 교실 체험 ↗’은 외부 별도 서비스입니다. SW 학생 학습 기록과 연결되지 않으며 새 탭에서 열립니다.

저장 문제가 있을 때: 계정·학급 승인·인터넷 연결을 확인하고 초안을 먼저 내려받으세요. 다른 기기와 충돌하면 서버 저장본을 비교하여 사용할 내용을 직접 선택합니다. 하루 150회, 활동 본문 20,000자 한도는 그대로 유지합니다. 공용 PC의 소유자 불명 예전 자료를 자동으로 가져오지 않습니다. 본인 백업 파일만 미리보기·본인 확인·충돌 확인 후 가져오세요.

현장 확인 순서: 학교 PC 2대에서 먼저 로그인·Python 첫 실행·저장·종료·다른 PC 복원을 시험하고, 물리 카메라 시작/종료를 확인한 다음 29대로 확대합니다. CI 가상 계정·가상 카메라 결과는 학교 PC 실증이 아닙니다.

## 교사용 관리실: 학생 승인과 정지 해제

1. [SW 교실](https://sw.englishmath.kr/?page=teacher)에 담당 교사 Google 계정으로 로그인한 후 **교사용 관리실**을 엽니다. 위쪽의 **관리할 학급**에서 담당 학급을 선택하면 승인·승인 대기·이용 중지 인원이 표시됩니다.
2. **승인 대기**인 학생은 **학생 승인** → 확인을 누르면 이용할 수 있습니다.
3. **승인됨**인 학생은 **이용 정지** → 확인을 누르면 저장·제출 권한이 일시 중단됩니다. 정지 전의 학습 기록과 제출 기록은 삭제하지 않습니다.
4. **이용 중지**인 학생은 **정지 해제 · 이용 재개** → 확인을 눌러 다시 승인할 수 있습니다. 정지 해제는 사용자 삭제나 신규 계정 생성이 아닙니다.
5. 교사 화면의 변경 완료 알림과 목록의 새 상태를 확인합니다. 학생은 로그인 상태에서 실시간으로 상태가 바뀌며, 연결이 끊긴 경우 **승인 상태 확인**을 눌러 다시 조회합니다.
6. 정지 상태에서 학생이 편집한 미저장 자료는 브라우저 임시 보관이므로 **초안 내려받기**로 백업하도록 안내하세요. 교사용 관리실의 **진도·제출물 확인**은 제출된 자료만 보여 주며, 학생 개인 초안은 열람하지 않습니다.

**문제 해결:** 학생 목록이 보이지 않으면 먼저 상단 계정이 교사 Google 계정인지, 담당 학급이 맞는지 확인합니다. ‘권한 없음’이 표시되면 Firebase의 `staff/{교사 UID}`에 담당 `classIds`가 등록되어 있는지 점검해야 합니다. 학생의 상태를 변경할 때 다른 교사가 먼저 수정했다면 목록을 다시 불러온 뒤 변경하세요. **수업 안내 화면의 ‘저장 대상이 아닙니다’는 관리자 계정 오류가 아니라 안내 페이지에 저장할 학습물이 없다는 의미입니다.**
