# Python 통합 실습 사용 안내

이 문서는 2026-11-07 개발 후보에 해당합니다. 운영 배포 완료 여부는 검증표의 K05~K07과 게시 저장소의 release-source.json으로 확인합니다.

## 학생

1. 수업 페이지를 열고 Google 계정으로 로그인합니다. 이름과 학년·반이 맞는지 확인합니다.
2. 처음 연 실습에는 선생님 코드가 들어 있습니다. 저장한 기록이 있으면 그 코드를 먼저 불러옵니다. 저장한 빈 코드도 그대로 복원합니다.
3. 숫자나 조건을 고쳐 **전체 실행**으로 결과를 확인합니다. `input()`이 있으면 입력 칸에 한 줄씩 값을 준비합니다.
4. **한 줄씩 보기**를 누른 뒤 **처음·이전·다음·마지막**으로 이동합니다. 방금 실행한 줄과 다음에 실행할 줄은 별도로 표시됩니다. 변수·표·그림·출력은 선택한 단계의 상태입니다. 이전으로 이동해도 난수나 입력을 다시 계산하지 않습니다.
5. **선생님 코드로 되돌리기**는 기본 코드로 바꿉니다. **되돌리기 취소**로 직전 코드를 복구할 수 있습니다.
6. **계정에 저장** 후 상단의 **클라우드 저장 완료**를 확인합니다. 연결 실패·저장 실패는 저장 완료가 아닙니다. 인터넷이 끊기면 화면을 유지하고 `.py` 또는 초안을 내려받습니다.
7. 다른 컴퓨터에서 같은 계정으로 로그인하고 **내 학습 보관함 → 이어서 작성**을 선택합니다. 코드와 입력은 복원되며, 직접 올린 CSV는 다시 선택합니다.
8. 공용 PC를 떠날 때 **이 PC 학습 마치기**를 누릅니다. 기존 정책에 따라 새로고침·탭 종료 뒤에는 다시 로그인합니다.

CSV는 UTF-8을 기본으로 읽습니다. 한글이 깨진 기존 CSV는 자료 인코딩에서 **CP949 / EUC-KR**을 선택한 뒤 올립니다. 예제 기본 자료는 미리 제공됩니다. 실제 학생 개인정보 대신 수업용 가상 자료를 사용합니다.

## 교사

- 기존 수업 순서·본문·문제를 유지합니다. 00 복습, 정규 10차시 50단계, 보충 탐구, 전체 과정, 자료 연결 실습, 그래픽 작품에서 공통 편집기를 사용합니다.
- 설명 조각은 필요한 준비 코드를 함께 제공하므로 앞 실습을 실행했는지에 의존하지 않습니다. 설치 명령과 실행 결과 예시는 Python 실행 코드와 구분합니다.
- 교사는 기존에 허용된 학급의 제출물만 확인합니다. 학생의 비공개 초안이 자동으로 교사에게 공개되도록 권한을 넓히지 않습니다. 학생이 **선생님께 제출**을 선택하면 제출 당시의 코드·답안을 확인합니다.
- 시험 범위와 배점은 기존 수업 안내 및 교사의 최종 안내를 따릅니다. 실행기 추가가 시험 범위 확정을 의미하지 않습니다.

## 실행 및 기록 범위

- 실제 Pyodide 0.28.3의 CPython, pandas 2.3.1, NumPy 2.2.5, Matplotlib 3.8.4를 사용합니다. 실행마다 별도의 Worker와 Python 공간을 만듭니다.
- 환경 준비 최대 120초, 실제 실행 최대 30초, 문자 출력 64 KiB입니다. 무한 반복은 **중지**로 종료할 수 있습니다.
- 단계 기록은 최대 20,000개 또는 64 MiB입니다. 기록 한도에 도달해도 계산은 별도 실행 한도까지 계속합니다. 일부 기록임을 명시하고 최종 결과를 따로 제공합니다.
- 일반 수업용 등록 예제 179개는 마지막 단계까지 검증합니다. 작품 4개는 원본 Python 계산을 기본 90프레임(최대 180프레임)으로 기록합니다. 작품의 **프레임별 상태 보기**는 실제 프레임을 표시한 Python 위치·변수·그림을 함께 보여줍니다. 일반 예제의 모든 줄 기록과 구분합니다. 웹 미리보기는 실시간 GUI 프로그램이 아닌 기록 재생입니다.
- Turtle은 수업에 쓰는 이동·회전·원·색·펜·위치·배경을 기록합니다. `speed()` 설정은 보관하지만 PC 창에서의 실제 대기 시간과 동일하게 재생하지 않습니다. `tracer(0)`·`update()` 상태를 표시하며 단계 그림은 해당 시점까지 계산한 그림입니다. GUI 클릭 대기와 모든 Tk 기능을 구현한 환경은 아닙니다.
- Tkinter/pygame 작품은 수업용 Canvas 호환 범위에서 실행합니다. 네온 작품의 기본 입력은 중앙 클릭 한 번입니다. `after()`·`tick()`은 수업 시계로 계산하며 실제 대기 없이 기록합니다. **VS Code용 .py**는 웹 기록 준비 코드를 제거한 원본 형태로 받습니다.
- 자료구조는 최대 32항목·깊이 4, 표는 32행·12열까지 보여주며 전체 크기와 생략을 표시합니다. 실제 계산 데이터는 이 표시 한도로 잘리지 않습니다.
- Matplotlib은 `show()` 시점에 표시를 기록합니다. `show()` 없이 종료하면 열려 있는 Figure를 종료 단계에 표시합니다.
- 코드·필요 입력·작은 답안만 계정에 저장합니다. 큰 실행 기록과 직접 올린 파일은 계정에 자동 전송하지 않습니다. 생성 파일은 실행 폴더에 새로 만들거나 수정한 CSV/TXT/JSON/PNG/SVG 중 2 MiB 이하를 내려받을 수 있습니다.

## 아직 별도 확인이 필요한 환경

실제 학교 PC 2대 및 29대 동시 사용은 클라우드 테스트로 대체할 수 없습니다. 학교 네트워크의 초기 다운로드, 저장·복원, 수업 중 반응 속도를 현장에서 확인해야 합니다. 실제 Windows Tk 창과 브라우저의 모든 픽셀이 같다고 보장하지 않습니다.
