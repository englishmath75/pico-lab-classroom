이번 작업은 기존 SW 홈페이지에 MK에서 검증한 회원 관리 흐름과 자유 코드 10개 보관 기능을 이식합니다. 사용자 지시에 따라 기존 SW 테스트 회원·학습 자료는 초기화 대상입니다. 홈페이지를 새로 만들거나 MK 수업 내용으로 교체하지 않습니다.

## 적용 기능과 사용 방법

| 대상 | 사용 방법 |
|---|---|
| 최초 학생 | Google 로그인 → 학교·실제 학년·반·이름 선택 → 선생님께 승인 요청 |
| 학생 정보 수정 | 내 등록 정보·변경 요청 → 수정 → 정보 변경 승인 요청. 승인 전에는 기존 정보 유지 |
| 교사 정보 검토 | 교사용 관리실 → 학생 현황 새로고침 → 변경 전후 확인 → 정보 변경 승인 또는 반려 |
| 잘못된 학생 등록 | 등록 취소. 기본 명단에서 제외하며 학습 자료는 일상적인 취소 동작으로 삭제하지 않음 |
| 등록 복구 | 등록 취소 학생도 보기 → 등록 복구·승인 대기 → 학생 승인 |
| 학생 재신청 | 등록 취소 상태에서 소속 수정 → 학급 재신청 → 교사 승인 |
| 정지 해제 | 이용 중지 해제 |
| 여러 코드 | 자유 Python 실습실 → 새 코드 또는 다른 이름으로 저장. 자유 코드 최대 10개, 수업 코드 별도 |
| 코드 다시 열기 | 실습 선택 또는 내 학습 보관함 → 이어서 작성 |
| 공간 비우기 | 내 학습 보관함 → 자유 코드 내려받기 → 코드 삭제. 삭제한 자유 코드와 최근 이력 제거, 제출본 유지 |

일반 회원 취소와 이번 한 번의 테스트 자료 전체 초기화는 별개입니다. 일반 취소는 복구할 수 있고, 전체 초기화는 되돌릴 수 없습니다.
