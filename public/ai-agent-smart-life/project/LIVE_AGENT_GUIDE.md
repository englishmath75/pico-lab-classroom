# AI AGENT SMART LIFE — 실제 생성형 AI 에이전트 교사용 실습

## 실습 목표
기존의 규칙 기반 `Agent Studio`와 실제 생성형 AI의 도구 선택을 비교합니다. 학생에게 LLM 계정을 만들거나 유료 API 키를 배포하지 않습니다. 교사가 시연할 수 있는 선택형 확장 실습입니다.

## 구현된 두 가지 모드
| 모드 | 실행 방식 | 추가 API 비용 | 학생 개인 계정 |
|---|---|---|---|
| 무료 웹 Agent Studio | JavaScript 도구 호출과 검증 (규칙 기반) | 없음 | 필요 없음 |
| `agent_live_teacher.py --dry-run` | 모의 LLM 응답, Python 도구 호출 검증 | 없음 | 필요 없음 |
| `agent_live_teacher.py --live` | 실제 OpenAI Responses API가 도구를 선택 | 사용량에 따라 발생 | 교사 API 계정만 |

**ChatGPT 정기 구독은 API 요금과 별개**입니다. 추가 결제 없이 진행하려면 무료 웹 체험 또는 `--dry-run`만 사용하십시오.

## 교사용 준비
1. `agent_live_teacher.py`와 `study_scores.csv`를 같은 폴더에 내려받습니다.
2. Python 3.10 이상을 준비합니다. 별도 외부 Python 패키지 설치는 필요하지 않습니다.
3. Windows PowerShell에서 해당 폴더로 이동하여 다음을 실행합니다.

```powershell
python .\agent_live_teacher.py --dry-run
```

실행 기록: `read_scores` → `score_stats` → `study_plan` → 최종 답변. 실습 내용은 공개된 가상 CSV만 사용합니다.

## 실제 생성형 AI 도구 호출 (선택)
API 계정이 있고 별도 요금이 발생할 수 있음을 확인한 **교사만** 진행합니다.

```powershell
$env:OPENAI_API_KEY = "교사 개인 비공개 API 키"
python .\agent_live_teacher.py --live
```

실행 전 '실행'이라고 입력하여 비용 발생을 승인해야 합니다. 다른 사람에게 API 키를 공유하지 말고, 화면 녹화·캡처에도 노출하지 마십시오. 수업 후 PowerShell 세션에서 제거할 수 있습니다.

```powershell
Remove-Item Env:OPENAI_API_KEY
```

이 코드는 키를 파일에 기록하지 않습니다. 키를 `.py`, `.html`, GitHub Pages 또는 학생 브라우저에 붙여넣어서는 안 됩니다. 실제 API 접근은 네트워크 상태와 계정 권한 및 잔액에 따라 성공 여부가 달라집니다.

## 안전한 실행 구조
- 사전에 제공한 `study_scores.csv` 파일만 읽습니다.
- **허용 도구는 세 가지**: `read_scores`(CSV 읽기), `score_stats`(평균·순위), `study_plan`(복습 계획)
- 외부 웹사이트 검색, 파일 삭제, 이메일 전송, 결제, 임의 Python 코드 실행 등의 도구는 없습니다.
- 모델이 다른 도구를 요청하면 서버 코드가 거절합니다.
- 최대 6차례 호출 루프, 각 단계 도구 실행 내역을 남깁니다.
- 요청에 `store: false`를 사용합니다. API 공급자 측 보존·처리 정책은 별도로 확인하십시오.
- 학생 개인정보, 실제 성적, 전화번호 등을 파일에 입력하지 마십시오.

## 학생 관찰 질문
1. 규칙 기반 스튜디오는 도구를 선택할 때 어떤 명시적 조건을 사용했나요?
2. 실제 생성형 AI는 같은 도구 중 무엇을 먼저 선택했나요? 도구 사용 순서가 매번 같은가요?
3. '생성한 설명'과 '도구에서 계산한 수치'는 어떻게 다른가요?
4. 잘못된 입력을 주었을 때 프로그램은 언제 중단하나요?
5. 실제 학생 계정 없이도 AI 에이전트의 핵심을 이해하는 데 어떤 실습이 더 적합할까요?

## 50분 수업 활용 예시 (10~11차시)
- 5분: 문제 상황(가상 과목별 점수표) 제시
- 10분: 도구 정의 및 입력/출력 비교
- 20분: 학생별 Agent Studio 무료 실습 및 JSON 설계도 저장
- 10분: 교사 `--dry-run` 실습 시연, 선택 시 실제 API 실험 비교
- 5분: 형성평가 및 학습 정리

## 한계
정적 GitHub Pages는 서버 API 키를 보관할 수 없습니다. 이 프로젝트는 전체 학급이 별도 API 계정 없이 이용할 수 있는 무료 실습을 기본으로 하고, 실제 LLM 도구 선택은 교사용 Python 콘솔 실습으로 제공합니다. 학생 개별 생성형 AI 에이전트를 웹에서 실시간 호출하는 기능은 **별도의 인증된 서버, 호출량 제한, 관리 승인, 예산**이 필요하며 현재 공개 웹사이트에서 자동으로 제공하지 않습니다.
