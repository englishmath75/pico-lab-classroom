# 실습 프로젝트: 나만의 학습 비서

## 구현 수준 구분
이 프로젝트는 **Python 규칙 기반 도구 실행 에이전트**입니다. 생성형 AI 모델이 도구를 동적으로 결정하지 않습니다. 에이전트의 핵심 구성 요소인 목표, 도구, 순차 실행, 검증을 직접 연습하기 위한 것입니다.

## 실행
1. `study_agent.py`, `study_scores.csv`를 같은 폴더에 둡니다.
2. Python 3.10 이상 설치 후 `python study_agent.py`를 실행합니다.
3. 과목별 점수를 수정하고 분석 결과를 비교합니다.

## 코드 이해
- `load_scores`: CSV 입력/데이터 검증
- `analyze_scores`: 평균·순위 계산
- `make_plan`: 점수가 낮은 과목부터 30분씩 권장
- `check_plan`: 과목 누락과 비정상 시간 확인
- `run_agent`: 목표 파악 → 작업 순서 결정 → 도구 실행 → 검증 → 결과 출력

## 도전 과제
- 데이터를 모두 삭제하면 오류 메시지가 나타나는지 테스트하기
- 평균보다 낮은 과목만 포함한 복습 계획 만들기
- 동일 점수인 과목의 우선순위 처리 방안 만들기
- `make_plan`에서 복습 시간을 과목별로 다르게 지정하기
- 정상/비정상/경계값 테스트 결과를 기록하기

## 생성형 AI 모델과 연결하려면?
실제 생성형 AI 기반 도구 호출을 하려면 교사가 관리하는 서버 측 모델 호출과 허용 도구 정의가 필요합니다. 인증·요금·학교 정책을 확인해야 하며 **개인 API 키를 학생 브라우저나 GitHub Pages에 직접 넣으면 안 됩니다.** 모델이 반환한 도구 호출 요청을 서버에서 검사·실행하고 결과를 다시 모델에 전달해야 합니다. 이 예제 자체는 유료 API를 사용하지 않습니다.
