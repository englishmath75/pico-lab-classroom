LLM은 무엇이 다른가요?

이 웹 실습은 파이썬 함수를 도구로 사용하는 원리를 규칙 기반으로 재현합니다. 실제 생성형 AI가 도구를 직접 선택하게 하려면 교사가 관리하는 모델 연결 환경이 추가로 필요합니다.

비용·개인정보 안내
무료 웹 실습은 API 키가 필요하지 않습니다. 실제 LLM 호출 실습은 교사가 별도 API 계정과 비용을 관리하는 선택 활동입니다. API 키를 공개 페이지, 코드 저장소 또는 학생 브라우저에 입력하지 마세요.
