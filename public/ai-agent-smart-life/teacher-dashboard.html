학생별 학습 기록 파일을 한 번에 확인합니다. 입력한 자료는 교사 브라우저에서만 분석하고 외부 서버로 전송하지 않습니다.

① 학습 기록 모으기

각 학생은 웹앱에서 익명 식별 코드(A01 등)를 입력하고 학습 기록 내보내기를 실행합니다. 교사는 수집한 JSON 파일을 여기에서 여러 개 선택합니다.

한 번에 최대 100개 파일(파일당 300KB)을 검사합니다. 다른 학년도 파일은 제외합니다. 같은 학생 코드를 여러 번 가져오면 최신 기록 하나를 사용합니다.

이 기능은 외부 데이터베이스에 저장하지 않는 파일 기반 통합 현황입니다. 자동 실시간 진도 동기화 기능은 아닙니다. 학생 이름·학번·실제 성적을 넣지 마시고 코드표가 필요한 경우 학교 내부에서 별도로 관리하세요.
