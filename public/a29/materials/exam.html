아두이노 수행평가 연습 문제지

스마트 야간 접근 경보 장치 만들기 · Arduino Uno R3 · 개별 실습 50분

학년·반번호성명장치번호

평가 방식 연습용으로 제공된 부품을 직접 배선하고, 학생용 기본 코드의 12개 빈칸을 완성한 뒤 Arduino Uno에 업로드합니다. 50분 종료 후 코드와 회로는 수정할 수 없으며 교사가 동일한 순서로 실물 동작을 확인합니다.

1. 수행평가 문제

  1. Arduino Uno와 제공된 부품을 이용하여 스마트 야간 접근 경보 장치를 제작하시오. HC-SR04, CDS, 가변저항은 실제 센서·입력값을 읽어 사용하며, 코드에 임의의 숫자를 넣어 측정값을 대신하지 마시오.
  2. 유효한 거리값이 20cm 미만이면 부저가 울리고, 20cm 이상이면 멈추게 하시오.
  3. 20cm 미만이면서 동시에 주변이 어두울 때만 LED가 켜지게 하시오.
  4. 점등 조건에서는 가변저항 입력 0~1023을 PWM 50~255로 변환하시오. 0은 LED 꺼짐 상태로 사용하고, 50~255는 켜진 상태의 밝기 조절 범위로 사용합니다. 50은 이번 평가에서 꺼짐과 점등을 구분하기 위해 정한 최소 밝기입니다.
  5. 시리얼 모니터에 거리, 조도, 가변저항, LED PWM 명령값, 부저 명령값을 반복 출력하시오.
  6. 제공된 코드 __01__~__12__를 완성하고 최종 .ino 파일을 제출하시오.

2. 정답 동작 조건

밝기거리LED부저
밝음20cm 이상꺼짐(0)꺼짐(0)
어두움20cm 이상꺼짐(0)꺼짐(0)
밝음20cm 미만꺼짐(0)울림(1)
어두움20cm 미만가변저항에 따라 50~255울림(1)
센서값 사용 실제 센서에서 읽은 값으로 동작해야 합니다. distance=15, light=100처럼 숫자를 직접 넣어 센서 측정을 대신하면 안 됩니다.
경계값 20cm는 “20cm 미만”에 포함되지 않습니다. 조도 기준은 LIGHT_LIMIT=400입니다. 초음파 무응답은 0cm 접근으로 처리하지 않습니다.

평가 전용 회로 연결표

부품의 방향과 핀 번호를 직접 확인하여 브레드보드에 구성합니다.

부품연결역할
HC-SR04VCC→5V / GND→GND / TRIG→D7 / ECHO→D8거리 측정
CDS + 10kΩ5V → CDS → 접점(A0) → 10kΩ → GND밝기 입력
가변저항양 끝→5V/GND / 가운데→A1LED 밝기 입력
LED + 220ΩD9 → 220Ω → LED(+) / LED(-)→GNDPWM 출력
수동 피에조D2 → 부저(+) / 부저(-)→GND경보 출력

3. 회로 구성 확인

  • 5V와 GND가 직접 연결되는 단락이 없어야 합니다.
  • 모든 부품은 공통 GND를 사용합니다.
  • CDS와 10kΩ 저항의 접점이 A0입니다.
  • 가변저항 가운데 단자(와이퍼)가 A1입니다.
  • LED에는 220Ω 저항이 직렬로 연결됩니다.
  • 통합 평가 LED 핀은 D9입니다.

4. 평가 중 허용 자료

  • 이 연습 문제지, 핀 연결표, 제공된 12개 빈칸 코드, 교사가 공통 안내한 함수 설명.
  • 타인의 완성 코드, 메신저 협업, 생성형 AI, 개인 완성 코드 반입은 사용하지 않습니다.
