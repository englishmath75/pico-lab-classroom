앞면: 실습 과제 · 뒷면: 학생용 코드 / A4 양면 1장 (연습용 예시)

학번 ____________성명 ______________연습 시간: 50분

실습 과제: 세 가지 독립 동작 만들기

Arduino Uno R3와 브레드보드 2개를 사용하여 초음파센서, 조도센서(CDS), 가변저항의 입력을 각각 받아 부저, 빨간 LED, 초록 LED가 독립적으로 동작하도록 회로와 프로그램을 완성하시오.

1. 핀 연결표 (암기하지 않고 참고)

부품Arduino 핀연결 조건
HC-SR04TRIG D7 · ECHO D8VCC 5V · GND 공통
CDS + 10kΩA05V → CDS → A0 접점 → 10kΩ → GND
가변저항A1 (가운데 단자)양 끝은 각각 5V·GND
빨간 LED + 직렬저항D9극성 주의 · 220~330Ω 직렬
초록 LED + 직렬저항D10극성 주의 · 220~330Ω 직렬
피에조 부저D2반대 단자는 GND

2. 반드시 완성할 동작

  1. 거리 경보: 초음파센서에서 실제로 측정한 거리가 20cm 미만이면 부저가 울리고, 20cm 이상이면 정지한다.
  2. 조도 경보: CDS를 통해 읽은 값이 400 미만이면 빨간 LED가 켜지고, 400 이상이면 꺼진다.
  3. 밝기 조절: 가변저항의 0~1023 입력값을 PWM 0~255로 변환하여 초록 LED의 밝기를 조절한다.
  4. 부저·빨간 LED·초록 LED가 서로 조건을 공유하지 않고 독립적으로 작동해야 한다.
  5. 시리얼 모니터(9600 bps)에 cds, pot, led, dist 값을 표시한다.

3. 확인하고 저장하기

□ 20cm 미만·이상에서 부저 반응 확인　□ 밝음·어두움에서 빨간 LED 확인

□ 가변저항 최솟값·최댓값에서 초록 LED 확인　□ 코드 저장·제출

뒷면: STEP 3 통합 코드. 앞면의 동작 조건을 읽고 __01__부터 __12__까지 알맞게 채우시오.

void setup() {
  pinMode(7, OUTPUT);
  pinMode(8, INPUT);
  pinMode(2, OUTPUT);
  pinMode(9, OUTPUT);
  pinMode(10, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int cds = __01__(A0);
  int pot = __02__(A1);
  int led = map(pot, 0, 1023, __03__, __04__);

  if (__05__) {
    digitalWrite(__06__, HIGH);
  } else {
    digitalWrite(9, __07__);
  }
  analogWrite(__08__, __09__);

  digitalWrite(7, LOW);
  delayMicroseconds(2);
  digitalWrite(7, HIGH);
  delayMicroseconds(10);
  digitalWrite(7, LOW);

  long duration = pulseIn(8, HIGH);
  float dist = duration * 0.034 / 2;

  if (__10__) {
    __11__(2, 1000);
  } else {
    __12__(2);
  }

  Serial.print("cds=");
  Serial.print(cds);
  Serial.print(" pot=");
  Serial.print(pot);
  Serial.print(" led=");
  Serial.print(led);
  Serial.print(" dist=");
  Serial.println(dist);
  delay(100);
}

힌트: analogRead(), map(), digitalWrite(), analogWrite(), tone(), noTone(), if/else 사용. 센서값을 임의 상수로 대체하지 마시오.
