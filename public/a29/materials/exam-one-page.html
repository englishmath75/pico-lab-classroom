학번: ____________이름: ______________총점: 100점 (기본 80 + 성취 20)
문제 상황
초음파센서로 물체까지의 거리를 감지합니다. 물체가 가까워지면 부저가 울리고, 주변이 어두울 때만 LED가 켜집니다. 가변저항으로 LED 밝기를 조절하고 센서·출력값을 시리얼 모니터에 표시하세요.

1. 회로 구성하기

부품Arduino 연결주의할 점
초음파 HC-SR04TRIG D7 / ECHO D8VCC 5V, GND 공통
CDS 조도센서A0CDS와 10kΩ 저항으로 전압 분배
가변저항 10kΩA1 (가운데 단자)양쪽 끝에 5V와 GND
LEDD9 (PWM)220Ω 직렬 저항, 극성 확인
피에조 부저D2다른 단자 GND

2. 빈칸 코드 12개 완성하기

  1. 제공된 arduino-assessment-starter.ino를 열고 __01__ ~ __12__를 올바른 코드로 채우세요.
  2. A0 조도값과 A1 가변저항값을 읽고, 가변저항 0~1023을 PWM 50~255로 바꾸세요.
  3. 초음파센서로 실제 거리를 측정해 조건을 작성하세요. 가짜 고정값으로 대체할 수 없습니다.
  4. 시리얼 통신 속도는 9600으로 합니다. 코드 컴파일·업로드까지 확인하세요.

3. 동작 조건 확인하기

주변 밝기물체 거리LED 출력부저
밝음20cm 이상꺼짐 (0)꺼짐
어두움20cm 이상꺼짐 (0)꺼짐
밝음20cm 미만꺼짐 (0)울림
어두움20cm 미만가변저항 따라 50~255울림

※ 조도 구분은 연습 코드 기준 CDS 원시값 400을 사용합니다. 실제 센서에 따라 값이 달라질 수 있습니다. 정확히 20cm는 경보 조건에 포함되지 않습니다.

4. 제출 전 최종 확인

□ 5V/GND 단락 없음　 □ 센서 3개 정상 입력　 □ LED·부저 정상 출력
□ 12개 빈칸 완성　 □ 4가지 조건 확인　 □ 시리얼 값 표시　 □ 최종 .ino 파일 저장
