메인 화면실습 3단계빈칸 코드 받기

통합 코드 · 연습 정답 12개

정답은 스스로 채워본 뒤 확인하세요. 빨강 D9는 CDS, 초록 D10은 가변저항, 부저 D2는 초음파가 각각 독립적으로 제어합니다. 연습용 자료이며 실제 평가 정답지는 아닙니다.
빈칸정답이유
01analogReadCDS(A0) 읽기
02analogRead가변저항(A1) 읽기
030초록 LED 최소 PWM
04255초록 LED 최대 PWM
05cds < 400어두움 판단
069빨강 LED D9
07LOW밝을 때 빨강 LED 끄기
0810초록 LED D10
09led초록 LED 밝기
10duration > 0 && dist < 20반사 신호가 있고 거리가 20cm 미만인지 판단
11tone부저 켜기
12noTone부저 끄기

최종 확인

20cm 미만이면 부저가 울리고, CDS 값이 400 미만이면 빨간 LED가 켜지며, 가변저항을 돌리면 초록 LED 밝기가 0~255로 변합니다.
