방법 ①

math와 turtle — 한 점씩 움직여 그래프 그리기

Turtle은 좌표를 계산한 뒤 pen.goto(x, y)로 점을 이동하며 선을 그립니다. pen.penup()은 선을 끊고, pen.pendown()은 이동 경로에 선을 그립니다.

# math 모듈과 반복문을 사용해 여러 수학 함수를 그리는 코드

import math
import turtle

screen = turtle.Screen()
screen.bgcolor("black")

pen = turtle.Turtle()
pen.speed(0)
pen.hideturtle()
pen.pensize(2)

# 좌표계 설정
pen.penup()
pen.goto(-300, 0)
pen.pendown()
pen.color("white")
pen.goto(300, 0)

pen.penup()
pen.goto(0, -300)
pen.pendown()
pen.goto(0, 300)

# 다항함수: y = ax^2 + b
pen.penup()
pen.color("cyan")
a, b = 0.01, -50
for x in range(-200, 201):
    y = a * (x**2) + b
    if abs(y) <= 300:
        pen.goto(x, y)
        pen.pendown()
    else:
        pen.penup()

# 지수함수: y = ae^x + b (스케일 조정)
pen.penup()
pen.color("magenta")
a, b = 5, -100
for x in range(-150, 60):
    y = a * math.exp(x / 20) + b
    if abs(y) <= 300:
        pen.goto(x, y)
        pen.pendown()
    else:
        pen.penup()

# 로그함수: y = aln(x) + b (스케일 조정)
pen.penup()
pen.color("yellow")
a, b = 50, 0
for x in range(1, 300):
    y = a * math.log(x / 10) + b
    if abs(y) <= 300:
        pen.goto(x, y)
        pen.pendown()
    else:
        pen.penup()

# 원의 방정식: x^2 + y^2 = r^2
pen.penup()
pen.color("lime")
r = 100
for angle in range(361):
    rad = math.radians(angle)
    x = r * math.cos(rad)
    y = r * math.sin(rad)
    pen.goto(x, y)
    if angle == 0:
        pen.pendown()

turtle.done()

# numpy 계산과 matplotlib 모듈을 사용해 여러 수학 함수를 그리는 코드

import numpy as np
import matplotlib.pyplot as plt

plt.style.use('dark_background')
fig, ax = plt.subplots(figsize=(10, 10))

# 변수 설정
a, b = 2, 3

# 1. 다항함수
x_poly = np.linspace(-5, 5, 400)
y_poly = a * x_poly**2 + b
ax.plot(x_poly, y_poly, color='cyan', label='Polynomial: y = ax^2 + b')

# 2. 지수함수
x_exp = np.linspace(-2, 2, 400)
y_exp = a * np.exp(x_exp) + b
ax.plot(x_exp, y_exp, color='magenta', label='Exponential: y = ae^x + b')

# 3. 로그함수
x_log = np.linspace(0.1, 10, 400)
y_log = a * np.log(x_log) + b
ax.plot(x_log, y_log, color='yellow', label='Logarithmic: y = aln(x) + b')

# 4. 원의 방정식
theta = np.linspace(0, 2*np.pi, 400)
r = a
x_circle = r * np.cos(theta)
y_circle = r * np.sin(theta)
ax.plot(x_circle, y_circle, color='lime', label='Circle: x^2 + y^2 = a^2')

# 5. 삼각함수 (사인, 코사인 추가)
x_trig = np.linspace(-2*np.pi, 2*np.pi, 400)
y_sin = a * np.sin(x_trig) + b
y_cos = a * np.cos(x_trig) + b
ax.plot(x_trig, y_sin, color='orange', label='Sine: y = asin(x) + b')
ax.plot(x_trig, y_cos, color='deeppink', linestyle='--', label='Cosine: y = acos(x) + b')

ax.set_title('High School Math Functions')
ax.grid(True, color='gray', alpha=0.5)
ax.legend()
ax.axis('equal')

plt.tight_layout()
plt.show()

3. 두 방법의 차이 비교

비교math + turtleNumPy + Matplotlib
계산반복문의 x 또는 각도마다 직접 계산np.linspace 배열 전체를 계산
그리기pen.goto(x,y)ax.plot(x,y)
표준 Python 모듈math, turtle외부 라이브러리 설치 필요
장점점 이동과 반복의 원리가 눈에 보임함수·그래프를 간결하게 표현, 데이터 분석에 연결
그래프 해석 주의: 원본 Matplotlib 코드는 ax.axis('equal')을 사용해 x축과 y축 단위 길이를 같게 그립니다. 여러 함수의 y값 범위가 다르므로 일부 곡선이 납작하게 보일 수 있습니다. 이는 실행 오류가 아닙니다.
