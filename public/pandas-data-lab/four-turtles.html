이름 네 개가 아니라, 객체 네 개를 만듭니다

pen1 = turtle.Turtle()
pen2 = turtle.Turtle()
pen3 = turtle.Turtle()
pen4 = turtle.Turtle()

turtle.Turtle()을 호출할 때마다 새 거북이 객체가 만들어집니다. pen1~pen4는 각각 다른 객체를 가리키는 이름입니다. 각 거북이는 현재 위치, 색상, 펜을 들었는지를 따로 기억합니다.

“pen2 = pen1이라고 쓰면 두 마리가 되나요?”

아닙니다. 두 이름이 같은 객체를 가리킵니다. 그 상태에서 pen2.color("magenta")를 실행하면 pen1로 부르던 그 거북이의 색도 바뀝니다. 독립된 네 거북이를 만들려면 Turtle()을 네 번 호출해야 합니다.

for P in (pen1, pen2, pen3, pen4):
    P.speed(0)
    P.pensize(2)
    P.hideturtle()
    P.penup()

P는 공통 설정을 적용할 때 각 거북이를 잠시 가리키는 짧은 이름입니다. 이번 모범답안의 보조 반복 변수이며, 그래프를 그리는 반복 변수 I와 역할이 다릅니다. 이 설정 반복문은 네 번 실행되고, 뒤의 그리기 반복문은 401번 실행됩니다.

hideturtle()은 커서 모양만 숨깁니다. “거북이가 안 보인다”는 것은 객체가 없다는 뜻이 아닙니다. 선은 그대로 그려집니다. speed(0)도 정지가 아니라 가장 빠른 이동 설정입니다.

Turtle() 네 번 → 네 객체. pen2 = pen1 → 한 객체에 이름 두 개.

색은 역할을 알려 주는 이름표입니다

pen1.color("cyan")
pen2.color("magenta")
pen3.color("yellow")
pen4.color("lime")
객체색상담당 그래프식
pen1cyan · 청록다항함수Y = AX² + B
pen2magenta · 자홍지수함수Y = Ce^(X/20) + D
pen3yellow · 노랑로그함수Y = E ln(X/10) + F
pen4lime · 밝은 초록원X² + Y² = R²

cyan이 원래 다항함수를 뜻하는 것은 아닙니다. 이 프로그램에서 pen1의 색을 cyan으로 정하고, pen1에게 다항함수 좌표를 넘겼기 때문에 청록색 포물선이 생깁니다. 색상 명령은 계산식과 독립적입니다. 색 문자열만 바꾸면 모양과 좌표는 그대로이고 색만 달라집니다.

실습에서는 색을 바꾸며 확인해도 좋지만, 이번 예상문제의 답안에서는 지정된 네 색상 조건을 지킵니다.

color()는 어떻게 보일지, X·Y 계산과 goto()는 어디에 그릴지를 정합니다.

짧은 변수로, 네 계산식을 정확하게

A = 0.01
B = -50
C = 5
D = -100
E = 50
F = 0
R = 100

A·B는 다항함수, C·D는 지수함수, E·F는 로그함수에 사용합니다. R은 원의 반지름입니다. math.exp()는 자연상수 e를 밑으로 하는 지수함수, 인수가 하나인 math.log()는 자연로그입니다.

담당계산식공통 I의 조건X 또는 각도 범위
pen1X = I - 200
Y = A * X**2 + B		모든 I: 0~400X: −200~200, 401개 후보
pen2X = I - 150
Y = C * math.exp(X / 20) + D		I < 210: 0~209X: −150~59, 210개
pen3X = I + 1
Y = E * math.log(X / 10) + F		I < 299: 0~298X: 1~299, 299개
pen4T = math.radians(I)
X = R * math.cos(T)
Y = R * math.sin(T)		I <= 360: 0~360각도: 0~360°, 361개

변수 X와 Y는 네 식에서 재사용합니다. 하지만 pen1.goto(X, Y)는 그 순간의 좌표값으로 pen1을 이동시킵니다. 다음 줄에서 X와 Y를 다른 값으로 계산해도, pen1이 저절로 따라 움직이지 않습니다.

로그는 입력이 양수여야 합니다. X=I+1로 시작하면 첫 입력 X/10은 0.1입니다. 원의 좌표 계산에서는 I를 도에서 라디안으로 바꾼 T를 sin·cos에 넣습니다. B. 호도법에서 다시 확인하기 →

다항함수의 후보는 401개지만 abs(Y) <= 300을 통과하는 점은 X=−187~187의 375개입니다. 첫 점은 펜을 든 채 이동하므로 선분은 374개입니다. 지수·로그의 주어진 구간은 모두 높이 조건을 통과하고, 원은 361개 좌표와 360개 선분으로 닫힙니다.

범위의 끝값과 if 조건을 함께 읽으세요. 반복 횟수, 이동 횟수, 선분 개수는 서로 다를 수 있습니다.

한 번 반복할 때, 네 거북이는 무엇을 할까요?

I 값 결정① pen1② pen2③ pen3④ pen4S.update()

for I in range(401): 안에서 Python은 위에서 아래로 실행합니다. pen1 블록을 처리하고, 조건이 맞으면 pen2, pen3, pen4를 차례로 이동시킵니다. 마지막으로 S.update()가 화면을 한 번 갱신합니다. 그다음 I가 1 증가해 같은 과정을 반복합니다.

“네 마리가 정말 동시에 계산하나요?”

아닙니다. 네 개의 독립 스레드에서 병렬 실행되는 프로그램이 아닙니다. 하나의 실행 흐름에서 각 객체를 순서대로 움직인 뒤 갱신하기 때문에 네 곡선이 함께 자라나는 것처럼 보입니다. 실제 PC의 성능에 따라 매우 빨리 완성될 수 있어, 미리보기에는 관찰용 속도 조절을 따로 제공합니다.

I=0을 직접 따라가 봅시다

순서계산동작
pen1X=−200, Y=350높이 범위 밖 → penup, 이동 없음
pen2X=−150, Y≈−99.9972첫 점으로 이동하고 펜 내리기
pen3X=1, Y≈−115.1293첫 점으로 이동하고 펜 내리기
pen4T=0, X=100, Y=0첫 점으로 이동하고 펜 내리기
화면S.update()현재까지의 그리기를 화면에 반영

첫 이동에서는 펜이 들려 있으므로 선분이 생기지 않습니다. 커서도 숨겼기 때문에 처음 한 번 갱신한 화면이 검게 보여도 오류가 아닙니다. 다음 이동부터 점 사이를 연결합니다.

goto와 pendown의 순서를 바꾸면?

if abs(Y) <= 300:
    pen1.goto(X, Y)
    pen1.pendown()
else:
    pen1.penup()

처음 유효한 점까지 펜을 든 채 이동한 뒤 내립니다. 먼저 pendown을 하고 goto를 하면 원점에서 첫 점까지 의도하지 않은 선이 생길 수 있습니다. 범위를 벗어나면 penup으로 연결을 끊습니다. 위의 조건은 점을 계산하기 전에 검사하는 것이 아니라 Y를 계산한 뒤 검사합니다.

각 함수의 조건은 서로 독립된 if입니다. 이를 하나의 if / elif / elif 사슬로 바꾸면 앞 조건이 참일 때 뒤 함수들을 건너뛰어 의도한 교차 그리기가 되지 않습니다. S.update()는 네 함수 블록 바깥이지만 공통 for 안에 둡니다.

계산 → 해당 거북이 이동 → 다음 거북이 → 화면 갱신. 이것이 한 번의 반복입니다.

표시·숨기기는 미리보기의 보기 옵션입니다. Python 모범답안의 계산 결과나 코드를 바꾸지 않습니다.

이 화면은 교육용 브라우저 미리보기이며 Python을 직접 실행하는 창은 아닙니다. 모범답안과 같은 좌표·색상·유효 구간·펜 상태로 그립니다. 관찰용 재생 속도와 현재 위치 점·좌표축은 보조 기능입니다. 기본 화면에서는 원본처럼 커서와 좌표축을 숨깁니다. 글꼴·선 가장자리·창 테두리는 실행 환경에 따라 다를 수 있습니다.

VS Code에서 실제 실행하기

  1. 아래 예상문제에 먼저 답안을 작성합니다. 그 뒤 모범답안을 열어 four_turtles.py를 내려받거나 복사합니다.
  2. VS Code에서 해당 파일을 열고 설치된 Python 인터프리터를 선택합니다. math와 turtle은 표준 모듈이므로 별도 pip 설치 대상이 아닙니다.
  3. 터미널에서 python four_turtles.py를 실행합니다. Windows에서 python 명령이 없고 py가 있다면 py four_turtles.py를 사용합니다.
  4. 검은 그래픽 창에서 네 곡선의 색과 모양을 확인합니다. 창을 닫으면 프로그램이 끝납니다.

Turtle은 Tk 그래픽 창을 띄울 수 있는 Python 환경이 필요합니다. 파일명을 turtle.py 또는 math.py로 저장하면 표준 모듈과 충돌할 수 있습니다. 학교 PC의 VS Code에서 실행하세요.

자신이 작성한 코드와 비교하세요. 정답을 복사해 덮어쓰기 전에, 놓친 줄의 역할을 먼저 설명해 보세요.

four_turtles.py · 실제 Python Turtle 실행용
원본 .py 다운로드
import math
import turtle

S = turtle.Screen()
S.bgcolor("black")
S.setup(760, 760)
S.setworldcoordinates(-330, -330, 330, 330)
S.tracer(0)

pen1 = turtle.Turtle()
pen2 = turtle.Turtle()
pen3 = turtle.Turtle()
pen4 = turtle.Turtle()

pen1.color("cyan")
pen2.color("magenta")
pen3.color("yellow")
pen4.color("lime")

for P in (pen1, pen2, pen3, pen4):
    P.speed(0)
    P.pensize(2)
    P.hideturtle()
    P.penup()

A = 0.01
B = -50

C = 5
D = -100

E = 50
F = 0

R = 100

for I in range(401):

    X = I - 200
    Y = A * X**2 + B

    if abs(Y) <= 300:
        pen1.goto(X, Y)
        pen1.pendown()
    else:
        pen1.penup()

    if I < 210:
        X = I - 150
        Y = C * math.exp(X / 20) + D

        if abs(Y) <= 300:
            pen2.goto(X, Y)
            pen2.pendown()
        else:
            pen2.penup()

    if I < 299:
        X = I + 1
        Y = E * math.log(X / 10) + F

        if abs(Y) <= 300:
            pen3.goto(X, Y)
            pen3.pendown()
        else:
            pen3.penup()

    if I <= 360:
        T = math.radians(I)
        X = R * math.cos(T)
        Y = R * math.sin(T)

        pen4.goto(X, Y)
        pen4.pendown()

    S.update()

turtle.done()

기존 Turtle 프로그램은 한 마리의 거북이를 이용하여 다항함수, 지수함수, 로그함수, 원의 방정식을 순서대로 그립니다. 이를 수정하여 pen1, pen2, pen3, pen4를 각각 생성하고, 각 거북이가 하나의 함수 그래프를 담당하도록 작성하시오.

  1. 거북이 객체 네 개를 생성합니다.
  2. 각 거북이에 cyan, magenta, yellow, lime 색상을 순서대로 지정합니다.
  3. 다항함수·지수함수·로그함수·원을 각각 담당하게 합니다.
  4. 하나의 그리기 반복문 안에서 네 거북이를 교차하여 이동시킵니다.
  5. 함수별 좌표 계산과 Turtle 명령을 올바르게 작성합니다.
  6. 계수 A=0.01, B=−50, C=5, D=−100, E=50, F=0, R=100을 사용하고, I·X·Y·T·S처럼 짧은 변수명을 사용합니다.
  7. S.tracer(0)과 S.update()를 이용하여 여러 그래프가 함께 그려지는 모습을 표현합니다.
