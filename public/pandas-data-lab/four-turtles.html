수정의 출발점 · 원본 전체 코드

아래는 한 마리의 pen이 좌표축과 네 그래프를 그리는 기본 원본입니다. 먼저 상단의 객체 생성·설정 부분을 찾고, 아래쪽에서 pen.이 반복되는 위치를 살펴보세요.

원본 · 한 마리로 순서대로 그리기
원본 .py 다운로드
# math 모듈과 반복문을 사용해 여러 수학 함수를 그리는 코드

import math
import turtle

screen = turtle.Screen()
screen.bgcolor("black")

pen = turtle.Turtle()
pen.speed(0)
pen.hideturtle()
pen.pensize(2)

# 좌표계 설정
pen.penup()
pen.goto(-300, 0)
pen.pendown()
pen.color("white")
pen.goto(300, 0)

pen.penup()
pen.goto(0, -300)
pen.pendown()
pen.goto(0, 300)

# 다항함수: y = ax^2 + b
pen.penup()
pen.color("cyan")
a, b = 0.01, -50
for x in range(-200, 201):
    y = a * (x**2) + b
    if abs(y) <= 300:
        pen.goto(x, y)
        pen.pendown()
    else:
        pen.penup()

# 지수함수: y = ae^x + b (스케일 조정)
pen.penup()
pen.color("magenta")
a, b = 5, -100
for x in range(-150, 60):
    y = a * math.exp(x / 20) + b
    if abs(y) <= 300:
        pen.goto(x, y)
        pen.pendown()
    else:
        pen.penup()

# 로그함수: y = aln(x) + b (스케일 조정)
pen.penup()
pen.color("yellow")
a, b = 50, 0
for x in range(1, 300):
    y = a * math.log(x / 10) + b
    if abs(y) <= 300:
        pen.goto(x, y)
        pen.pendown()
    else:
        pen.penup()

# 원의 방정식: x^2 + y^2 = r^2
pen.penup()
pen.color("lime")
r = 100
for angle in range(361):
    rad = math.radians(angle)
    x = r * math.cos(rad)
    y = r * math.sin(rad)
    pen.goto(x, y)
    if angle == 0:
        pen.pendown()

turtle.done()

연습창에 작성한 코드가 있습니다. 원본으로 바꾸면 현재 내용이 교체됩니다. 필요한 답안은 먼저 파일로 내려받으세요.

찾아볼 줄: pen = turtle.Turtle() → 이 호출은 거북이 객체 하나를 만듭니다.
2

Turtle은 클래스, pen1·pen2는 객체를 가리키는 이름

turtle은 모듈 이름이고, 그 안의 Turtle은 거북이의 기능을 정의한 클래스입니다. turtle.Turtle()처럼 괄호를 붙여 호출하면 그 클래스로부터 새 거북이 객체(인스턴스)를 만듭니다. pen1은 만들어진 객체를 가리키는 변수입니다.

원본 · 객체 하나

pen = turtle.Turtle()

하나의 객체가 현재 위치·색상·펜 상태를 기억합니다. 원본은 같은 pen에게 작업을 계속 맡깁니다.

수정 · 서로 다른 객체 네 개

pen1 = turtle.Turtle()
pen2 = turtle.Turtle()
pen3 = turtle.Turtle()
pen4 = turtle.Turtle()

Turtle()을 네 번 호출했습니다. 각 객체가 자기 위치·색상·펜 상태를 따로 기억하므로 그래프별로 역할을 나눌 수 있습니다.

turtle.Turtle 클래스Turtle() 호출마다 새 객체 생성
pen1다항함수 담당자기 위치 · 색 · 펜 상태
pen2지수함수 담당자기 위치 · 색 · 펜 상태
pen3로그함수 담당자기 위치 · 색 · 펜 상태
pen4원 담당자기 위치 · 색 · 펜 상태

이름만 늘리면 객체도 늘어날까요?

pen1 = turtle.Turtle()
pen2 = pen1

위 코드는 객체 하나를 두 이름으로 가리킵니다. pen2.color("magenta")를 실행하면 pen1로 가리키는 그 객체의 색도 바뀝니다. 독립된 거북이가 필요하면 pen2 = turtle.Turtle()로 새로 만들어야 합니다.

네 객체를 만들어 둔 경우에는 pen2.goto(50, 20)으로 pen2만 이동합니다. pen1·pen3·pen4의 위치는 그대로입니다. 이것이 각 그래프의 마지막 위치를 따로 유지하며 그릴 수 있는 이유입니다.

변수 이름을 복사하는 것과 새 객체를 생성하는 것은 다릅니다.
3

원본에서 바꿀 곳은 세 군데입니다

  1. 객체 생성

    pen = turtle.Turtle() 한 줄을 pen1~pen4를 만드는 네 줄로 바꿉니다.

  2. 각 객체의 설정

    원본의 speed(0)·hideturtle()·pensize(2)를 네 객체 모두에 적용합니다. pen1만 설정해도 다른 객체가 자동으로 같은 설정을 받지는 않습니다.

  3. 명령을 받을 객체 지정

    각 그래프 블록에서 pen.color(), pen.penup(), pen.goto(), pen.pendown()의 pen을 담당 객체 이름으로 바꿉니다. 수학식과 반복 범위는 원본 그대로 둡니다.

설정은 해당 객체에 적용됩니다

pen1.speed(0)
pen1.hideturtle()
pen1.pensize(2)

pen2.speed(0)
pen2.hideturtle()
pen2.pensize(2)

같은 방식으로 pen3과 pen4도 설정합니다. speed(0)은 빠른 이동, hideturtle()은 커서 숨기기, pensize(2)는 선 두께 설정입니다.

지수함수 블록을 바꾸는 예

# 원본
pen.color("magenta")
pen.goto(x, y)

# 수정
pen2.color("magenta")
pen2.goto(x, y)

계산된 x, y는 그대로 사용하고, 그 좌표로 이동할 객체만 pen2로 지정합니다. 이 블록 안의 다른 pen 명령도 pen2로 맞춥니다.

원본의 부분수정 후 담당색상
좌표축pen1white
다항함수pen1cyan
지수함수pen2magenta
로그함수pen3yellow
원pen4lime

좌표축은 pen1이 먼저 그리도록 합니다. 원본의 좌표축 부분에서도 pen을 pen1로 바꿉니다. 그 뒤 다항함수 블록 첫머리의 pen1.penup()과 pen1.color("cyan")을 그대로 사용하면 축과 곡선이 불필요하게 연결되지 않습니다. 이미 그린 흰색 축은 색을 바꾸어도 그대로 남습니다.

생성할 객체 수를 늘리고 → 각각 설정하고 → 그래프 블록의 담당 이름을 바꿉니다.

시험예상 · 원본을 수정해 완성하세요

네 그래프를 여러 거북이가 나누어 그리도록 하려 합니다. 위의 원본 코드를 보고 다음을 작성하시오.

  1. 객체 생성·설정: 원본의 pen = turtle.Turtle()부터 pen.pensize(2)까지를 수정하여 pen1, pen2, pen3, pen4 객체를 각각 만들고, 네 객체 모두에 같은 속도·커서 숨김·선 두께를 적용하시오.
  2. 역할 지정: 좌표축과 다항함수는 pen1, 지수함수는 pen2, 로그함수는 pen3, 원은 pen4가 그리도록 각 블록의 pen 명령을 수정하시오. 색상은 원본의 white·cyan·magenta·yellow·lime을 유지하시오.
  3. 이유 설명: 객체를 여러 개 만드는 이유와, pen2 = pen1로 대신할 수 없는 이유를 서술하시오.

표시·숨기기는 미리보기의 보기 옵션입니다. Python 모범답안의 계산 결과나 코드를 바꾸지 않습니다.

교육용 브라우저 미리보기입니다. 주관식 입력창의 코드를 실행한 결과가 아닙니다. 원본의 흰색 축은 보조 표시로 켤 수 있고, 참고 실행 코드의 기본 화면에는 축이 없습니다.

함께 그리는 참고 코드 · 필요할 때만 보기

객체 생성과 역할 나누기를 익힌 뒤 살펴보는 확장 예시입니다. 수식·반복 횟수의 세부 해설은 이 페이지에서 다루지 않습니다.

four_turtles.py · 교차 그리기 참고
참고 코드 .py 다운로드
import math
import turtle

S = turtle.Screen()
S.bgcolor("black")
S.setup(760, 760)
S.setworldcoordinates(-330, -330, 330, 330)
S.tracer(0)

pen1 = turtle.Turtle()
pen2 = turtle.Turtle()
pen3 = turtle.Turtle()
pen4 = turtle.Turtle()

pen1.color("cyan")
pen2.color("magenta")
pen3.color("yellow")
pen4.color("lime")

for P in (pen1, pen2, pen3, pen4):
    P.speed(0)
    P.pensize(2)
    P.hideturtle()
    P.penup()

A = 0.01
B = -50

C = 5
D = -100

E = 50
F = 0

R = 100

for I in range(401):

    X = I - 200
    Y = A * X**2 + B

    if abs(Y) <= 300:
        pen1.goto(X, Y)
        pen1.pendown()
    else:
        pen1.penup()

    if I < 210:
        X = I - 150
        Y = C * math.exp(X / 20) + D

        if abs(Y) <= 300:
            pen2.goto(X, Y)
            pen2.pendown()
        else:
            pen2.penup()

    if I < 299:
        X = I + 1
        Y = E * math.log(X / 10) + F

        if abs(Y) <= 300:
            pen3.goto(X, Y)
            pen3.pendown()
        else:
            pen3.penup()

    if I <= 360:
        T = math.radians(I)
        X = R * math.cos(T)
        Y = R * math.sin(T)

        pen4.goto(X, Y)
        pen4.pendown()

    S.update()

turtle.done()

객체 이해를 확인하는 채점 기준

20점 기준 예시입니다. 실제 학교 시험의 배점은 선생님이 최종 결정합니다. 제공된 수학식의 유도나 공통 반복문 재작성은 이번 문제의 채점 항목에 넣지 않습니다.

turtle.Turtle()을 네 번 호출하여 pen1~pen4에 연결 · 객체당 2점speed(0), hideturtle(), pensize(2)를 모두 적용 · 객체당 1점각 그래프의 pen 명령을 담당 객체로 일관되게 변경 · 그래프당 1점. 좌표축은 pen1 사용독립된 상태와 역할 설명 2점 · pen2=pen1은 새 객체를 만들지 않는다는 설명 2점

독립된 거북이 객체 네 개 생성8점

내 답안 자기 점검

자기 점검 0/4개 · 참고 점수 0/20점. 코드 정확성을 자동 채점한 점수가 아닙니다.

이 문제에서 자주 놓치는 부분

  • pen2 = pen1로 이름만 늘리기 → 새 객체는 생기지 않습니다.
  • pen1만 설정하기 → pen2~pen4의 설정도 각각 필요합니다.
  • 위쪽 생성 부분만 바꾸고 아래쪽에 pen.goto() 남기기 → 해당 블록의 담당 이름으로 모두 맞춥니다.
  • 좌표축 부분의 pen을 남기기 → 이번 수정본에서는 pen1이 좌표축을 그립니다.
같은 클래스로 객체를 여러 개 만들고, 각 객체에 다른 일을 맡길 수 있습니다.
