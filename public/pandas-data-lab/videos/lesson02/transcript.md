## 07:17 · C 평균 계산

이제 books 열 뒤에 점 mean과 빈 괄호를 붙입니다. mean은 평균을 구하는 메서드입니다. 선택한 열에 평균 계산을 실행하라고 요청하는 것입니다. 손으로 계산하면 3 더하기 5 더하기 2를 세 명으로 나누므로 10 나누기 3입니다. 실행하면 3.3333333333333335처럼 긴 소수가 나옵니다. 평균이 정수가 아닐 수도 있다는 뜻입니다. 컴퓨터의 소수 표현 때문에 마지막 자리가 우리가 손으로 적은 무한소수와 조금 달라 보일 수 있습니다. 책을 실제로 3.33권 읽었다는 뜻이 아니라 세 사람의 독서량을 하나의 대표값으로 요약한 결과입니다. 한 사람의 값을 뜻하는 것도 아닙니다.

```python
import pandas as pd

data = {
    'name': ['A', 'B', 'C'],
    'books': [3, 5, 2]
}

df = pd.DataFrame(data)

print(df)
print(df['books'].mean())

```

실행값 또는 안내:
```text
  name  books

2    C      2

```
