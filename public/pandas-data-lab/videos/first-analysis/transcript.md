## 08:22 · 가격의 쉼표 제거 후 숫자 변환

화면 표시: unit_price: "3,500" → 3500 / 숫자로 바꾼 뒤 계산

```python
df['unit_price'] = pd.to_numeric(
    df['unit_price'].str.replace(
        ',', '', regex=False
    ), errors='coerce'
)
print('수량 결측:',
      df['quantity'].isna().sum(), '행')
```

출력 또는 확인할 내용:
```text
원본 행·열: (16, 5)
```

```text
이익: 비용 자료가 없어 확정 불가
```
