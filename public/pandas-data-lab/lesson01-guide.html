import pandas as pd

import: 라이브러리 불러오기 · pd: 별칭 · DataFrame: 2차원 표 · print: 출력 · head(): 앞 5행 보기

② DataFrame의 행·열·인덱스 완전 이해

중요! DataFrame의 열 이름(item, sales)은 데이터 행에 포함되지 않고, 왼쪽 인덱스(0, 1, 2)는 데이터 열에 포함되지 않습니다.

인덱스(Index)열 개수에 포함 안 됨itemsales
0juice12
1bread20
2milk16

행(Row) = 3개 (juice, bread, milk) · 열(Column) = 2개 (item, sales) · 인덱스 = 0, 1, 2

STEP A. 행과 열의 개수 확인하기

print(df.shape)      # (3, 2)
print(df.index)      # RangeIndex(start=0, stop=3, step=1)
print(df.columns)    # Index(['item', 'sales'], dtype='object')

shape는 (행 개수, 열 개수), index는 행의 이름표, columns는 열 이름입니다.

STEP B. 인덱스를 1, 2, 3으로 바꾸는 두 가지 방법

방법 1 — 처음 DataFrame을 만들 때 지정

df = pd.DataFrame({
    'item': ['juice', 'bread', 'milk'],
    'sales': [12, 20, 16]
}, index=[1, 2, 3])
print(df)

방법 2 — 이미 만든 DataFrame의 인덱스를 변경

df.index = range(1, len(df) + 1)
print(df)

두 방법 모두 출력되는 인덱스는 1, 2, 3입니다. 그래도 df.shape는 계속 (3, 2)입니다.

STEP C. 인덱스 이름과 실제 행 위치는 다릅니다

print(df.loc[1])    # 인덱스 이름이 1인 행
print(df.iloc[0])   # 첫 번째 위치의 행

위 두 코드는 현재 예제에서 모두 juice 행을 선택합니다. loc은 이름, iloc은 0부터 시작하는 위치를 기준으로 합니다.

STEP D. 인덱스를 실제 열로 추가한다면?

df2 = df.reset_index()
print(df2.shape)    # (3, 3)

reset_index()를 사용하면 기존 인덱스가 index라는 일반 데이터 열로 들어가므로 3행 3열이 됩니다.

개념 확인 — 인덱스를 1부터 시작하면 DataFrame의 열 개수도 늘어날까요?

정답: 아닙니다. 인덱스 번호만 바뀌면 3행 2열 그대로입니다. reset_index()로 일반 열로 변환할 때 열이 하나 늘어납니다.

↔ 행(Row)은 한 학생의 기록, ↕ 열(Column)은 같은 항목의 모음, 인덱스(Index)는 행을 구별하는 이름표입니다.

④ 1차원 · 2차원 · 3차원

1차원 Series = 한 방향의 목록 → [65, 78, 90]

2차원 DataFrame = 행 × 열의 표 → 학생 × 과목

3차원 이상 ndarray / Tensor = 여러 표를 층처럼 쌓은 배열 → 학급 × 학생 × 과목

import numpy as np
scores = np.array([
    [[80, 90], [70, 85]],
    [[95, 88], [75, 92]]
])
print(scores.shape)  # (2, 2, 2)

참고: pandas의 DataFrame 자체는 2차원입니다. NumPy는 다차원 수치 배열에 적합하고, 딥러닝에서는 텐서를 활용합니다. 과거 pandas의 Panel은 현재 제거되었습니다.

⑤ pandas라는 이름의 유래

Panel Data(패널 데이터)라는 통계 용어에서 유래했습니다. 패널 데이터는 같은 대상을 여러 시점에 걸쳐 반복 관찰한 자료입니다. 동물 판다에서 직접 따온 이름은 아닙니다.

예: 학생 A의 2024년 점수와 2025년 점수를 함께 분석하는 자료. 패널 데이터도 2차원 DataFrame으로 표현할 수 있습니다.
