① pandas와 DataFrame

📄 CSV→🐼 pandas→📊 DataFrame→📈 시각화·해석

pandas는 표 데이터를 읽고 정리·분석하는 파이썬 라이브러리입니다.

import pandas as pd

data = {'name':['A','B','C'], 'score':[65,78,90]}
df = pd.DataFrame(data)
print(df)
print(df.head())

import: 라이브러리 불러오기 · pd: 별칭 · DataFrame: 2차원 표 · print: 출력 · head(): 앞 5행 보기

② 행·열·인덱스 구별하기

인덱스이름점수
0A65
1B78
2C90

↔ 행(Row)은 한 학생의 기록, ↕ 열(Column)은 같은 항목의 모음, 인덱스(Index)는 행을 구별하는 이름표입니다.

③ 1차원 · 2차원 · 3차원

1차원 Series = 한 방향의 목록 → [65, 78, 90]

2차원 DataFrame = 행 × 열의 표 → 학생 × 과목

3차원 이상 ndarray / Tensor = 여러 표를 층처럼 쌓은 배열 → 학급 × 학생 × 과목

import numpy as np
scores = np.array([
    [[80, 90], [70, 85]],
    [[95, 88], [75, 92]]
])
print(scores.shape)  # (2, 2, 2)

💡 pandas의 DataFrame 자체는 2차원입니다. NumPy는 다차원 수치 배열에 적합하고, 딥러닝에서는 텐서를 활용합니다. 과거 pandas의 Panel은 현재 제거되었습니다.

④ pandas라는 이름의 유래

Panel Data(패널 데이터)라는 통계 용어에서 유래했습니다. 패널 데이터는 같은 대상을 여러 시점에 걸쳐 반복 관찰한 자료입니다. 동물 판다에서 직접 따온 이름은 아닙니다.

예: 학생 A의 2024년 점수와 2025년 점수를 함께 분석하는 자료. 패널 데이터도 2차원 DataFrame으로 표현할 수 있습니다.

⑤ 기말 대비 개념 확인

문제 1. import pandas as pd에서 pd의 의미는?정답: pandas 라이브러리의 별칭입니다.
문제 2. DataFrame의 차원과 두 축의 이름은?정답: 2차원, 행(Row)과 열(Column)입니다.
문제 3. df.head()는 기본적으로 무엇을 반환할까요?정답: 데이터프레임의 앞 5개 행입니다.
문제 4. shape가 (2, 2, 2)인 배열의 의미는?정답: 세 축 각각의 길이가 2인 3차원 배열입니다.
문제 5. pandas라는 이름의 유래는?정답: Panel Data라는 통계 용어에서 유래했습니다.
문제 6. 그래프를 그렸다면 분석은 끝난 걸까요?정답: 아닙니다. 자료의 출처와 한계를 확인하고 결과를 해석해야 합니다.
