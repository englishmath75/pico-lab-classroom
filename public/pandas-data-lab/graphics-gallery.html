HTML 파일은 VS Code에서 내용을 확인하고 저장한 뒤 Chrome 등의 브라우저에서 열면 됩니다. Python 파일은 VS Code의 Python 인터프리터를 선택하고 실행합니다. Tkinter는 데스크톱 GUI 환경이 필요하고, Pygame 예제는 해당 패키지가 설치되어 있어야 합니다.

Windows VS Code 실행 순서

HTML (zero01, zero05): 파일을 내려받아 저장한 후 VS Code에서 열고, 브라우저로 실행합니다. Python 실행 버튼으로 실행하는 파일이 아닙니다.

Pygame (zero02): 아래 명령 중 자신에게 맞는 설치 명령을 VS Code 터미널에 입력한 후 zero02.py를 실행하세요.

py -m pip install pygame
py zero02.py

# py 명령이 없는 환경
python -m pip install pygame
python zero02.py

Tkinter (zero03, zero04, zero06): 일반적인 Windows Python 설치에서는 Tkinter가 함께 제공됩니다. py zero03.py처럼 해당 파일을 실행합니다. Tk 창을 띄울 수 없는 온라인 Python 실행기에서는 작동하지 않을 수 있습니다.

오류 해결: ModuleNotFoundError는 설치한 패키지와 VS Code의 Python 인터프리터가 일치하는지 확인하세요. pygame 설치가 Python 버전에서 지원되지 않는 경우 pygame-ce 설치 가능성을 확인할 수 있으나, 코드에서 import pygame을 사용하는 것은 동일합니다. 일부 원본은 그래픽 라이브러리 버전이나 성능에 따라 실행 오류가 있을 수 있으며, 수업 자료에서는 원본을 임의 변경하지 않습니다.
