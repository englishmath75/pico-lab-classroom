열 가지 차시를 모두 먼저 공부하실 필요는 없습니다. 아래 1차시를 직접 실행하고 설명할 수 있으면 첫 수업을 시작할 수 있습니다.

  1. 10분 · 개념 읽기 — 1차시 개념 안내에서 pandas·DataFrame·행·열·인덱스를 확인합니다. 접힌 다음 차시/선택 참고는 오늘 건너뜁니다.
  2. 20분 · 학생처럼 실행 — 1차시 실습의 ‘Python 미리 준비’를 누른 뒤 5단계를 직접 입력·실행합니다. 출력이 없는 import도 성공임을 확인합니다.
  3. 15분 · 설명 연습 — 아래 코드 해설을 보며 “왜 3행 2열인가?”, “인덱스를 바꿔도 왜 크기가 같은가?”를 말로 설명해 봅니다.
  4. 10분 · 수정·오류 경험 — 판매량 숫자 하나를 바꿔 실행하고, 괄호 하나를 지웠다가 복구합니다. .py 저장과 결과 확인을 연습합니다.
  5. 5분 · 마무리 — 확인 문제 두 개를 풀고, 내일 수업의 종료 지점을 확인합니다.

학생이 물을 질문 · 바로 답하기

왼쪽 0, 1, 2도 한 열 아닌가요?

표 옆에 붙은 행의 이름표입니다. 이 예제의 데이터 열은 item과 sales 두 개뿐입니다. df.shape는 인덱스를 제외하고 (3, 2)를 반환합니다.

맨 위 item과 sales도 한 행 아닌가요?

데이터의 항목을 알려주는 열 이름입니다. 상품 데이터는 juice, bread, milk 세 행입니다.

1, 2, 3으로 바꾸면 첫 행의 위치도 1인가요?

행의 이름표만 바뀝니다. 첫 행의 위치는 여전히 0입니다. loc과 iloc의 차이는 3차시에서 다룹니다.

왜 shape에는 괄호가 없고 mean에는 괄호가 있나요?

shape는 이미 가진 표의 크기 정보를 읽는 속성입니다. mean()은 평균을 계산하도록 호출하는 메서드입니다. print(df.shape)의 바깥 괄호는 print 함수의 괄호입니다.

import를 했는데 결과가 안 나와요.

import는 도구를 불러오는 명령이라 보통 출력이 없습니다. 오류 없이 실행됐다면 준비된 것입니다. 표를 보려면 print(df)를 씁니다.

웹에서는 되는데 VS Code에서 pandas가 없다고 나와요.

웹 실습 환경과 PC의 Python 환경은 별개입니다. 교사가 사용하는 Python 환경과 패키지 설치 상태를 확인합니다. 오늘 실습은 웹에서 이어갈 수 있습니다.

수업 전 확인

  • 학교 PC에서 메인 → 1차시 → 실습을 열고 ‘Python 미리 준비’를 확인합니다. 초기 다운로드 속도는 학교망에 따라 다릅니다.
  • 전체 코드가 누적되어 있는지, 출력이 없더라도 오류 없이 끝나는 단계가 있음을 확인합니다.
  • 코드·CSV는 10차시 Python·CSV 묶음으로 한 번에 받을 수 있습니다. 3차시에서는 sports_fictional.csv와 .py를 같은 작업 폴더에 둡니다.
  • 학습 기록은 브라우저 로컬 저장이며 자동 제출되지 않습니다. PC를 옮길 때 ‘학습 기록 백업’과 ‘기록 복원’을 사용합니다.
  • 코드가 오래 실행되면 ‘실행 중지’를 누릅니다. 입력 내용은 유지되고 실행 환경만 다시 준비됩니다.
VS Code 보조 실행 안내

PC에 Python과 VS Code가 준비된 경우, 실습 폴더를 열고 같은 Python 인터프리터에서 실행합니다. 필요한 패키지는 해당 환경에 설치합니다.

python -m pip install pandas matplotlib
python lesson_01.py

설치와 import는 다릅니다. 설치는 환경에 도구를 준비하는 과정이고, import는 작성한 프로그램에서 그 도구를 불러오는 과정입니다.
