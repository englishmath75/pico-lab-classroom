03 Python이 판단하게 해 볼까요?

실시간 애니메이션은 JS, 아래 결과는 진짜 Python 실행 결과입니다. 버튼을 누른 순간의 세 숫자만 복사합니다. 실행 후 표정을 바꾸어도 이미 실행한 결과는 바뀌지 않습니다.

① 웃음 분기if / elif / else0.7과 0.4를 바꾸면?
② 눈 감김 판단if blink_score >= 0.6한 순간의 값으로 깜빡임 전체를 알 수 있을까요?
③ 기울기 판단abs(head_tilt_deg)부호가 달라도 크기는 같아요.

가상 실험값 0, 0, 0으로 시작합니다.

조건문이 정한 반응 상태
교사용 50분 수업 지도안 · 현장 점검
  1. 0~5분 · 시연과 정보 보호

    웃음이 숫자가 되는 과정을 보여줍니다. 얼굴 영상은 전송하지 않으며 마음을 읽는 AI가 아님을 설명합니다.

  2. 5~15분 · 친구 선택과 연결

    8종 중 선택하고 카메라 권한을 확인합니다. 차단·미설치 PC는 가상 모드로 동일하게 참여합니다.

  3. 15~25분 · 세 미션

    웃기, 눈 감았다 뜨기, 좌우 기울이기. 감지 실패 시 조명·거리·가림을 한 가지씩 바꿉니다.

  4. 25~35분 · 기준 비교

    웃음 기준 0.5와 0.8에서 결과를 비교합니다. 같은 동작도 사람·조명에 따라 점수가 달라지는 이유를 토론합니다.

  5. 35~45분 · Python 조건문

    현재 값을 보내고 실행합니다. if/elif/else의 경계값을 예측하고 0.39, 0.40, 0.69, 0.70을 가상 모드로 실험합니다.

  6. 45~50분 · 발표와 종료

    성공·실패 사례와 수정한 조건을 발표합니다. 학습 종료를 누르고 카메라 LED가 꺼졌는지 확인합니다.

학교 학생 PC 2대 현장 점검 — 아직 미실시

  • 두 PC에서 서로 다른 아바타를 선택하고 실제 웃음·눈 깜빡임·좌우 기울기를 확인합니다.
  • 카메라 끄기·탭 이동 후 LED 꺼짐과 미리보기 제거를 확인합니다.
  • Python 실행, 학교망에서 모델 준비 시간과 지연을 기록합니다.
  • 2대 확인 후 5대, 이후 29대 순서로 확대합니다. 동시 29대 성능은 미검증입니다.
