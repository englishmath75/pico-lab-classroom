우리 지역 인구는 정말 줄고 있을까?

국가통계포털(KOSIS) → 내 손으로 CSV 내려받기 → 파일 확인·정제 → Pandas 분석 → Matplotlib 그래프 → 근거 기반 보고서

학습 목표와 최종 결과물

학생마다 본인이 관심 있는 지역을 선택합니다. 인구가 늘거나 줄었다는 주장을 연도별 인구수와 증감률 그래프로 검증합니다.

최종 제출 4개

① 원본 CSV ② 정제 CSV ③ 인구 추세 그래프 PNG ④ 결과·한계 5문장 보고서

반드시 지켜요

웹앱의 가상 인구와 혼동하지 말 것. KOSIS 통계표명, 작성기관, 기준일, 단위, 다운로드 날짜를 기록할 것.

STEP 01

통계포털 접속부터 자료 선택까지

  1. KOSIS 국가통계포털 열기를 누릅니다. 여기서 사용할 ‘통합데이터포털’은 공식 국가통계포털 KOSIS입니다.
  2. 상단 검색창에 주민등록인구현황을 입력하고 검색합니다. 결과에서 행정구역(시군구)별 주민등록인구수 또는 같은 취지의 주민등록인구 통계표를 선택합니다. 표 이름은 갱신될 수 있으니 작성기관·단위도 확인하세요.
  3. 통계표에서 항목은 '총인구수' 또는 '계'에 해당하는 인구수 1개를 선택하고, 행정구역은 본인이 살펴볼 시군구 1곳을 고릅니다. 성별 구분이 있다면 '계(전체)'를 선택합니다.
  4. 시점에서 '년' 단위를 선택할 수 있으면 연간 자료를 선택합니다. 연간 단위가 없으면 매년 12월처럼 같은 달의 월별 자료를 선택하세요. 가능하면 2020년 이후 연속된 5개 연도의 값을 선택합니다.
  5. 조회를 눌러 화면에 5개 이상 시점과 인구 값이 나타나는지 확인합니다. 특정 연도의 자료가 없으면 실제로 제공되는 연도만 사용하세요.
  6. 통계표의 다운로드 아이콘 또는 메뉴를 클릭합니다. 파일 형식 CSV를 선택한 후 다운로드합니다. 메뉴 위치는 화면 배치에 따라 달라질 수 있습니다.
  7. 파일을 population_kosis_original.csv로 이름을 바꿔 보관합니다. 내려받은 원본은 절대 직접 덮어쓰지 않습니다.

공식 안내: KOSIS 통계표 조회·CSV 다운로드 설명서. 화면이 다르더라도 다운로드 메뉴에서 CSV 선택하는 절차를 따릅니다.

STEP 02

내 CSV 파일을 직접 열어 구조 확인

직접 받은 .csv를 선택하면 표의 첫 부분을 웹에서 미리 볼 수 있습니다. 파일은 서버에 업로드하지 않고 현재 브라우저에서만 읽습니다. 통계자료의 파일 구조는 표마다 다릅니다.

아직 선택한 CSV가 없습니다.

한글이 깨지면 CP949/EUC-KR로 바꿔 다시 읽으세요. 열 제목이 첫 줄이 아니면 헤더 줄을 조정하세요. 쉼표가 아닌 다른 구분자 파일은 VS Code에서 먼저 확인해야 합니다.

STEP 03

연도와 인구 열 찾기 · 내 분석 코드 생성

CSV 열이 시점/행정구역/인구수 같은 세로형일 수도 있고, 2020,2021,2022...처럼 가로형일 수도 있습니다. 가장 쉬운 방법은 엑셀이나 스프레드시트로 두 열(year,population)만 새 CSV로 저장하는 것입니다.

권장 정제 형식

year,population
2020,123456
2021,122900
2022,121350
2023,120700
2024,119800

위 숫자는 형식을 보여 주는 가상 예시이며 실제 통계가 아닙니다.

직접 정제하는 방법

  1. 원본 CSV를 엑셀 또는 스프레드시트로 엽니다.
  2. 연도와 본인이 선택한 지역의 전체 인구 값만 남깁니다.
  3. A1에는 year, B1에는 population을 입력합니다.
  4. 인구 열의 쉼표 천단위 기호, '명' 문자, 합계행, 출처·주석행을 제거합니다.
  5. CSV UTF-8 형식으로 population_clean.csv를 따로 저장합니다.

정제는 숫자를 새로 만들어 내는 작업이 아닙니다. 값 변경 없이 필요한 연도와 인구수만 골라 동일 단위로 정리하세요. 자동 열 추정은 데이터 의미를 확인할 수 없으므로 사용하지 않습니다.

분석 코드 전체 보기
STEP 04
VS Code에서 Python 실행
  1. 바탕화면에 KOSIS_PROJECT 폴더를 만들고 population_kosis_original.csv, population_clean.csv, 다운로드한 analyze_population.py를 넣습니다.
  2. VS Code에서 파일 → 폴더 열기로 이 폴더를 엽니다.
  3. 터미널을 열고 python -m pip install pandas matplotlib를 실행합니다.
  4. python analyze_population.py를 실행합니다. Windows에서 python 명령이 없으면 py analyze_population.py를 사용하세요.
  5. 터미널에 정제 자료, 인구 증감량·증감률이 표시되고 같은 폴더에 population_trend.png, population_result.csv가 생성됩니다.
  6. 출력 그래프를 열어 연도별 증가·감소를 확인합니다. 인구 단위가 명이면 그래프에도 '명'이라고 표시합니다.

STEP 05
실제 데이터 해석 보고서 완성
개인 주민등록번호, 성적, 실명 등 개인정보를 입력하지 마세요. 통계의 공공 집계자료만 사용합니다.
