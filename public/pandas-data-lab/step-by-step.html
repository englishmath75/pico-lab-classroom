    4. 결과 해석·학습 기록
    웹에서 먼저
    한 줄 입력 → 실행 → 오류 수정 → 다음 단계. 실행 전에 예상하고 실제 출력과 비교합니다.
    VS Code에서 다시
    ‘.py 저장’ → VS Code로 열기 → 터미널에서 필요 시 python -m pip install pandas matplotlib → python 파일명.py. Python 설치가 필요합니다.
    학습 진도와 입력 내용은 현재 기기의 브라우저에만 저장됩니다. 교사에게 자동 제출되지 않습니다. 실제 성적·실명·개인정보를 입력하지 마세요. Python 엔진은 최초 실행 시 인터넷에서 다운로드하며, 학교망에서 막히면 .py 파일을 VS Code로 실행할 수 있습니다.
    

    5. 차시 확인 문제
    선택 1. 실제 인구 자료 분석탐구 보고서 작성하기 →
    오류가 나면 여기부터 확인하세요
    • NameError: import 또는 df를 만드는 줄이 빠지지 않았는지 확인합니다. 매번 편집기의 전체 코드를 실행합니다.
    • SyntaxError: 괄호·따옴표의 짝과 쉼표를 확인합니다.
    • FileNotFoundError: 파일 이름과 작업 폴더를 확인합니다. 3차시 웹 실습에는 CSV가 자동 준비됩니다.
    • KeyError: 열 이름의 대소문자와 철자를 확인합니다.
    • 첫 준비가 막히면 실행 중지 후 다시 시도하세요. 전체 예제 .py와 CSV는 내려받아 사용할 수 있습니다.
