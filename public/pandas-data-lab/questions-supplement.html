질문 01 · 핵심 개념

1. 8비트는 몇 가지 값을 나타낼까요?

비트(bit)는 0 또는 1 하나입니다. 바이트(byte)는 보통 비트 8개입니다. 8개의 비트가 각각 두 상태를 가지므로 2⁸ = 256가지 서로 다른 상태를 나타냅니다.

같은 8비트 값최소중간 예시최대
2진수000000001000000011111111
10진수0128255
16진수0080FF

중요: 위 표는 부호 없는(unsigned) 8비트 정수의 범위입니다. 부호 있는 8비트 정수는 일반적으로 -128~127을 나타낼 수 있습니다.

왜 16진수 두 자리인가요? 16진수 한 자리는 0~F의 16가지 상태 = 4비트입니다. 따라서 두 자리는 16×16=256가지, 즉 8비트와 대응합니다.

값을 움직여 직접 비교하기

10진수128
2진수 · 8자리10000000
16진수 · 2자리80
Python의 16진수 정수 리터럴0x80

Arduino PWM과 연결

Arduino Uno의 analogWrite(LED, 0)은 PWM 출력에서 0% 듀티에 해당하고, analogWrite(LED, 255)는 약 100% 듀티에 해당합니다. 128은 약 50% 듀티입니다.

analogWrite(LED, 0);     // 출력 꺼짐
analogWrite(LED, 128);   // 듀티 약 50%
analogWrite(LED, 255);   // 듀티 약 100%
analogWrite(LED, 0xFF);  // 같은 값 255를 16진수로 표현

PWM은 빠른 켜짐/꺼짐 비율을 조절하는 방식입니다. 사람이 느끼는 LED 밝기가 반드시 숫자에 선형 비례하지는 않습니다. PWM 가능한 핀과 회로 조건도 확인하세요.

질문 02 · 색상 코드

2. 왜 웹 색상은 #FF0000처럼 쓰나요?

RGB는 빨강(R), 초록(G), 파랑(B) 세 빛의 값을 조합하는 방식입니다. 각 색 채널을 0~255, 즉 8비트로 표현하면 R·G·B가 각 2자리 16진수가 됩니다.

색상 채널16진수10진수
빨강 RFF255
초록 G000
파랑 B000
합친 색#FF0000빨강

웹 표기 규칙: 맨 앞의 #는 “이 뒤는 색상 코드”라는 CSS/HTML의 표기 관례입니다. 그 뒤 여섯 자리가 RRGGBB를 나타냅니다.

따라서 #FF는 이 수업의 기본 #RRGGBB 형식으로는 색상 전체를 표현하지 못합니다. 참고로 CSS는 세 자리 #RGB와 네 자리 #RGBA 축약형도 지원하지만, Turtle에서 배우는 기본 예제는 여섯 자리로 작성하는 것이 안전합니다.

RGB 색을 직접 섞어 보기

255
87
51

현재 색상 코드: #FF5733

한 채널에서 255는 최대 강도, 0은 해당 채널이 꺼진 상태입니다.

import turtle

turtle.pencolor("#FF5733")  # Hex 색상
turtle.forward(100)

turtle.pencolor("cyan")     # 영문 색상 이름
turtle.forward(100)

turtle.done()
주의: 웹 CSS에서 8자리 #RRGGBBAA는 투명도(Alpha)까지 표현합니다. 예: #FF000080은 약 50% 투명도의 빨강입니다. Python Turtle의 pencolor()에는 기본적으로 #RRGGBB 여섯 자리 형식을 사용하세요. 8자리 CSS 색상 형식을 그대로 넣으면 오류가 날 수 있습니다.
질문 03 · 진법과 프로그래밍

3. 왜 0xFF라고 쓰고, 앞에 0x를 붙이나요?

0x는 16진수 정수 리터럴이라는 뜻의 접두사입니다. 영어 문자 FF만 쓰면 Python에서 변수 이름으로 해석되지만, 0xFF라고 적으면 정수 255가 됩니다.

맨 앞의 0과 뒤의 x를 조합해 “이 숫자는 16진수입니다”라고 알리는 프로그래밍 언어의 표기 규칙입니다. 비슷하게 Python은 0b로 2진수, 0o로 8진수를 구분합니다.

print(0b11111111)   # 2진수 → 255
print(255)          # 10진수 → 255
print(0xFF)         # 16진수 → 255

print(hex(255))     # '0xff' 문자열
print(int("FF", 16))  # 255

color = "#FF0000"   # 웹·Turtle용 색상 문자열
value = 0xFF        # Python의 숫자 255
분야표현의미
2진수 정수0b11111111255
8진수 정수0o377255
16진수 정수0xFF255
웹·Turtle 색상 문자열"#FF0000"빨간색(R=255, G=0, B=0)

핵심 차이: 0xFF는 하나의 숫자이고, "#FF0000"은 색상 형식의 문자열입니다. 0xFF와 255는 같은 정수값이지만, #FF0000은 빨강·초록·파랑 채널 세 개를 함께 나타냅니다.
