1. 리스트·튜플·딕셔너리의 차이

괄호 모양과 값을 읽고 바꾸는 방법을 비교합니다. 리스트와 딕셔너리는 데이터 분석에서 자주 사용합니다. 튜플은 리스트처럼 순서와 인덱스가 있지만, 원소를 직접 수정할 수 없습니다.

a = [ ] · 리스트

순서 있음 · 원소의 추가·수정·삭제 가능

a = [30, 40, 50, 60, 70]
t = ( ) · 튜플

순서 있음 · 읽기는 가능하지만 원소 변경 불가

t = (10, 20, 30, 20, 40)
d = { } · 딕셔너리

키와 값의 쌍으로 저장하고, 키를 이용해 조회·수정

d = {"name": "영수", "kor": 90, "eng": 85}
기억하세요. 리스트와 튜플은 [0]처럼 인덱스로 원소를 읽습니다. 딕셔너리는 d["name"]처럼 키로 값을 읽습니다. 튜플 (3,)의 쉼표는 원소 하나만 들어 있는 튜플을 표시합니다.

2. 리스트의 여섯 명령어와 슬라이싱

먼저 기존에 배운 append · insert · remove · del · sort · reverse를 복습합니다. 그다음 슬라이싱으로 특정 범위의 원소를 가져오는 방법을 살펴봅니다.

명령의미이번 실습 코드
append()맨 뒤에 추가a.append(9)
insert()지정 위치에 삽입a.insert(2, 17)
remove()지정 값의 첫 번째 항목 삭제a.remove(60)
del인덱스 위치의 원소 삭제del a[0]
sort()오름차순으로 정렬a.sort()
reverse()현재 원소 순서를 역순으로a.reverse()

슬라이싱: 리스트의 일부를 가져오기

원소를 삭제한 직후의 리스트는 a = [40, 17, 50, 70, 9]입니다. 이 값을 기준으로 다음 결과를 예상해 보세요.

코드출력 결과의미
a[1:4][17, 50, 70]1번부터 4번 직전까지
a[:3][40, 17, 50]처음부터 3번 직전까지
a[2:][50, 70, 9]2번부터 끝까지
a[::2][40, 50, 9]처음부터 두 칸씩
a[::-1][9, 70, 50, 17, 40]역순으로 읽은 새 리스트
주의: 슬라이싱은 마지막 인덱스를 포함하지 않습니다. a[::-1]은 역순 결과를 새 리스트로 만들어 반환하고, a.reverse()는 원래 리스트 자체의 순서를 바꿉니다.

for i in range(len(keys)):

5. 튜플 패킹(Packing)과 언패킹(Unpacking)

패킹은 여러 값을 하나의 튜플로 묶는 것입니다. Python에서는 box = 1, 2, 3처럼 괄호를 생략하고 쉼표로 구분해도 튜플이 됩니다. 실제 출력이 (1, 2, 3)이고 type(box)가 tuple인 것으로 확인할 수 있습니다.

언패킹은 튜플 안에 들어 있는 여러 값을 변수 각각에 나누어 담는 것입니다. a, b, c = box라고 쓰면 a에는 1, b에는 2, c에는 3이 들어갑니다.

패킹과 언패킹만 따로 연습하기

# 1. 괄호 없이 쉼표로 값을 묶어 튜플 만들기 (패킹)
box = 1, 2, 3

# 2. 값과 자료형 확인
print(box)
print(type(box))

# 3. 튜플의 값을 세 변수로 나누기 (언패킹)
a, b, c = box
print(a, b, c)

이 코드의 실행 결과

(1, 2, 3)
<class 'tuple'>
1 2 3
주의: 위의 짧은 예제는 별도 파일에서 실행하세요. 큰 통합 코드의 중간에 a, b, c = box를 끼워 넣으면 기존 리스트 변수 a가 숫자 1로 바뀌어 뒤쪽 리스트 반복문에서 오류가 날 수 있습니다. 통합 코드에서는 이를 피하려고 x, y, z = box를 사용합니다.
한 줄 정리: box = 1, 2, 3은 패킹, x, y, z = box는 언패킹입니다. 언패킹할 때는 이 예제처럼 변수 개수와 원소 개수가 맞아야 합니다.

6. 딕셔너리와 반복문 읽는 방법

d["name"]은 키를 사용해 값을 가져옵니다. d.get("math", 0)은 "math"라는 키가 없으면 0을 반환합니다. d["math"] = 95를 실행한 뒤에는 새로운 키와 값이 추가됩니다. d.pop("math")는 키를 삭제하면서 그 값을 반환하므로 val에 95가 들어갑니다.

d.keys()는 키, d.values()는 값, d.items()는 키와 값의 쌍을 확인하는 데 사용합니다. for k, v in d.items()의 k, v 역시 키와 값의 쌍을 언패킹하는 형태입니다.

반복문의미예시 결과
for item in a:리스트의 값 직접 순회70, 50, ...
for item in t:튜플의 값 직접 순회10, 20, ...
for key in d:딕셔너리는 기본적으로 키 순회name 영수, kor 100
for i in range(len(a)):리스트 인덱스와 값 함께 출력0 70, 1 50, ...
for i in range(len(keys)):딕셔너리 키 목록의 순번 사용0 name 영수, 1 kor 100
Pandas와 연결: 리스트는 열에 들어갈 여러 값을 모을 때, 딕셔너리는 열 이름과 값들을 연결할 때 많이 사용합니다. 튜플은 df.shape처럼 행과 열의 개수를 알려 주는 값으로도 나타납니다.

7. 확인 문제 — 답을 생각한 뒤 열어 보세요

① a[::2]는 어떤 결과를 출력하나요?

[40, 50, 9]입니다. 0번 인덱스부터 두 칸 간격으로 가져옵니다. 리스트를 정렬하기 전의 값입니다.

② t.count(20)과 t.index(30)의 결과는?

둘 다 2입니다. count(20)은 20의 개수를, index(30)은 30이 처음 나오는 인덱스를 알려 줍니다.

③ box = 1, 2, 3은 어떤 자료형인가요?

튜플입니다. 쉼표로 값을 묶어 패킹한 것으로 type(box)를 출력하면 <class 'tuple'>이 나옵니다.

④ d.get("math", 0)이 처음에는 0인 이유는?

아직 "math"라는 키가 없기 때문입니다. 두 번째 인수 0이 기본값으로 반환됩니다. 이후 d["math"] = 95로 추가합니다.

⑤ for k, v in d.items()에서 k와 v는 각각 무엇인가요?

각 딕셔너리 항목의 키와 값입니다. items()에서 꺼낸 쌍을 두 변수에 언패킹하여 읽습니다.
