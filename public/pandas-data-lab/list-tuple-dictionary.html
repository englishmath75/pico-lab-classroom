2. 배웠던 리스트 명령어 6개 복습

리스트를 만들고 추가 → 삽입 → 값 삭제 → 위치 삭제 → 정렬 → 역순으로 차례대로 실행합니다. 출력 결과가 어떻게 달라지는지 확인하세요.

명령의미예시
append()맨 뒤에 원소 추가A.append(100)
insert()지정한 인덱스에 삽입A.insert(1, 85)
remove()해당 값의 첫 번째 항목 삭제A.remove(70)
del지정 위치의 원소 삭제del A[0]
sort()오름차순으로 정렬A.sort()
reverse()현재 순서를 거꾸로 뒤집기A.reverse()
꼭 구분하세요. remove(70)은 값이 70인 원소를 삭제하고, del A[0]은 0번 위치의 원소를 삭제합니다. sort()는 값 크기로 정렬하지만, reverse()는 크기와 관계없이 순서를 뒤집습니다. del은 A.del() 같은 메서드가 아니라 Python 문장입니다.

3. 한 개의 Python 파일로 실습하기

아래 전체 코드를 복사해 VS Code에서 data_types.py로 저장하고 실행하세요. 세 가지 자료구조의 변화가 차례대로 출력됩니다. 추가 패키지를 설치할 필요는 없습니다.

실습용 Python 파일 다운로드
# 리스트, 튜플, 딕셔너리 비교 - 한 파일로 실습
A = [10, 20, 70, 40]
B = (22, 55, 11, 99, 33)
C = {"name": "민지", "gender": "여", "age": 17}

print("=== 1. 리스트: 추가·수정·삭제 가능 ===")
print("처음:", A)
A.append(100)
print("append:", A)
A.insert(1, 85)
print("insert:", A)
A.remove(70)
print("remove:", A)
del A[0]
print("del:", A)
A.sort()
print("sort:", A)
A.reverse()
print("reverse:", A)

print("\n=== 2. 튜플: 읽기는 가능, 수정은 불가 ===")
print("처음:", B)
print("B[0]:", B[0])
print("count(55):", B.count(55))
print("index(11):", B.index(11))
# B.append(100)   # 주석을 풀면 AttributeError
# B[0] = 99       # 주석을 풀면 TypeError

print("\n=== 3. 딕셔너리: 키(Key)와 값(Value) ===")
print("처음:", C)
print("이름:", C["name"])
print("나이:", C.get("age"))
C["age"] = 18
C["job"] = "학생"
print("수정·추가:", C)
print("keys:", list(C.keys()))
print("values:", list(C.values()))
print("items:", list(C.items()))
del C["gender"]
print("del:", C)
실습 팁: 튜플 부분에서 주석 처리된 B.append(100) 또는 B[0] = 99를 한 줄씩 풀어서 실행하면 오류를 확인할 수 있습니다. 오류를 확인한 후 다시 주석으로 바꾸세요.

나이: 17

값: ['민지', '여', 18, '학생']

5. 튜플은 간단히, 딕셔너리는 Pandas와 연결하기

튜플 B는 리스트처럼 B[0]으로 원소를 읽을 수 있지만 append()나 원소의 재할당은 지원하지 않습니다. count()와 index()는 조회할 때 사용하는 대표 메서드입니다.

딕셔너리 C는 번호가 아니라 키를 이용합니다. 예를 들어 C["name"]은 이름을, C.get("age")는 나이를 확인합니다. C["age"] = 18은 기존 값을 수정하고, C["job"] = "학생"은 새 키를 추가합니다.

이후 Pandas에서는 열 이름을 키로 하고 여러 값을 리스트로 묶은 딕셔너리를 pd.DataFrame()에 전달해 표를 만들 것입니다. 오늘은 이 연결만 이해하면 충분합니다.

수업 정리: 데이터 분석에서 리스트는 여러 값을 나열할 때, 딕셔너리는 열 이름과 데이터를 연결할 때 중요합니다. 튜플은 특히 df.shape에서 (행, 열)처럼 결과를 반환할 때 다시 등장합니다.

6. 확인 질문 — 답을 생각한 뒤 열어 보세요

A.sort()와 A.reverse()는 같은 명령인가요?

아닙니다. sort()는 값의 순서로 정렬하고, reverse()는 현재 순서를 반대로 뒤집습니다.

튜플에 append()를 사용하면 어떻게 되나요?

튜플에는 append()가 없으므로 AttributeError가 발생합니다. 튜플은 원소를 직접 추가하거나 변경할 수 없습니다.

딕셔너리에서 C[0]은 첫 번째 사람 정보인가요?

아닙니다. 여기서는 숫자 인덱스 대신 "name", "age" 같은 키를 사용해야 합니다. C[0]은 해당 키가 없으면 KeyError가 발생합니다.
