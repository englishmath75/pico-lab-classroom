1. 교과서 원문과 웹앱 자료의 차이

이 페이지는 선생님이 제공한 교사용 교과서 PDF의 단원 구성·페이지를 확인해 작성한 자체 수업 안내입니다. 교과서 본문을 공개적으로 복제하지 않습니다. 원문 전체 열람은 학교가 보유한 정식 교과서 또는 출판사에서 허용한 교사용 시스템을 이용하세요.

확인한 PDF: 「소프트웨어와 생활 교사용 교과서 PDF3단원_2026용」(44쪽). 실제 교과서 표기 쪽수는 82~125쪽입니다.

2. 교과서 학습 내용 · 원문 페이지 대응

교과서 쪽확인된 내용·활동웹앱에서 배우는 기술
84~86사회 현상 속 데이터 활용, 기후 변화 문제와 가설분석 질문 만들기
87데이터 분석의 중요성, 정형·비정형·반정형 데이터CSV와 DataFrame, 데이터 유형
88~91데이터 수집·처리·분석 절차, 공개자료 탐색read_csv, head, dtypes, 자료 품질
92~99실습: 기후 변화 추이를 알려주는 시각화 분석 자료데이터 정제, 집계, Matplotlib
100~104실습: 기후 변화와 관련해 주로 언급되는 단어 찾기비정형 자료 이해, 문자열 전처리(확장)
105~106데이터 분석의 사회적 가치, 활동 정리해석·윤리·탐구 보고서
109~114융합 진로: 스포츠 기록 분석 연구원, 선수 기록 분석·선발팀 구성필터·정렬·groupby·스포츠 실습
116~123융합 프로젝트: 우리나라 인구 변화 현황 알아보기인구 증감률·추세 그래프·출처 확인
124~125대단원 정리 및 평가형성평가·기말 연습문제

교과서의 본문 문장·삽화·원본 문항 대신 학생들이 직접 실행할 수 있는 별도 Python 예시를 제공합니다.

3. 10차시 수업의 핵심 기준

① 질문과 자료 출처를 확인하고 ② CSV를 표로 읽으며 ③ 데이터를 정제하고 ④ 그래프를 만들고 ⑤ 수치·현상·윤리를 근거 있게 설명합니다. NumPy 선수학습은 요구하지 않습니다. Pandas의 합치기·피벗·시계열은 선택 심화입니다.
