# 아두이노 수행평가 연습 — 스마트 야간 접근 경보 장치

- 대상: 2학년 소프트웨어와 생활
- 시간: 50분
- 보드: Arduino Uno R3
- 입력: HC-SR04 초음파센서, CDS 조도센서, 가변저항
- 출력: LED, 수동 피에조 부저, 시리얼 모니터
- 점수: 기본점수 80.0 + 실습 성취점수 20.0 = 100.0

## 핵심 동작
1. 유효한 거리가 20cm 미만이면 부저가 울린다.
2. 20cm 이상이면 부저가 멈춘다.
3. 가까우면서 동시에 어두울 때만 LED가 켜진다.
4. LED가 켜지는 상태에서는 가변저항으로 PWM 밝기를 50~255 범위에서 조절한다.
5. 시리얼 모니터에 거리, 조도, 가변저항, LED PWM 명령값, 부저 명령값을 출력한다.

## 평가 전용 핀
- HC-SR04 TRIG D7 / ECHO D8
- CDS A0
- 가변저항 A1
- LED PWM D9
- 수동 피에조 D2

상세 문제, 전체 83개 채점 기준, 자기점검은 웹앱의 수행평가 연습 화면에서 확인합니다.
