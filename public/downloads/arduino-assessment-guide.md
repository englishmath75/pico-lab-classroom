# 아두이노 수행평가 연습 — 스마트 야간 접근 경보 장치

- 대상: 2학년 소프트웨어와 생활
- 시간: 50분
- 보드: Arduino Uno R3
- 입력: HC-SR04 초음파센서, CDS 조도센서, 가변저항
- 출력: LED, 수동 피에조 부저, 시리얼 모니터
- 점수: 기본점수 40 + 수업참여 20 + 태도 20 + 실습활동 20 = 100점

## 코드의 조도 기준값
`const int LIGHT_LIMIT = 400;`은 `LIGHT_LIMIT`라는 정수 기준값을 400으로 정하고 프로그램 실행 중 바꾸지 않는다는 뜻입니다. 이번 회로에서는 `light < 400`이면 어두움, `light >= 400`이면 밝음으로 판단합니다.

## 핵심 동작
1. HC-SR04, CDS, 가변저항은 실제 장치에서 읽은 값을 사용한다. `distance = 15`, `light = 100`처럼 임의 숫자를 코드에 직접 넣어 센서 측정값을 대신하지 않는다.\n2. 유효한 거리가 20cm 미만이면 부저가 울린다.
3. 20cm 이상이면 부저가 멈춘다.
4. 가까우면서 동시에 어두울 때만 LED가 켜진다.
5. LED가 켜지는 상태에서는 가변저항으로 PWM 밝기를 50~255 범위에서 조절한다. PWM 전체 범위는 0~255이지만, 이번 평가에서는 0을 '꺼짐' 전용으로 두고 50~255를 '켜진 상태의 밝기'로 사용한다. 따라서 50은 Arduino의 특별한 기준이 아니라 평가용 최소 밝기이다.
6. 시리얼 모니터에 거리, 조도, 가변저항, LED PWM 명령값, 부저 명령값을 출력한다.

## 평가 전용 핀
- HC-SR04 TRIG D7 / ECHO D8
- CDS A0
- 가변저항 A1
- LED PWM D9
- 수동 피에조 D2

상세 문제, 전체 83개 채점 기준, 자기점검은 웹앱의 수행평가 연습 화면에서 확인합니다.
