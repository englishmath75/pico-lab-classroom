상태: 구현 브랜치의 수업 콘텐츠 초안 v1 (2026-10-16)

코드 정본: englishmath75/pico-lab-classroom
학생 웹앱: /ai-agent-smart-life.html (배포 확인 후 공개)
이전 학습 연결: Arduino 센서→입력→판단→출력 ↔ Python 표 데이터→분석→예측→도구 실행→검증

## A. 교육 목표
- 문제 해결: 실생활의 반복 업무를 목표·입력·출력·검증으로 분해한다.
- 데이터: CSV/Pandas·Matplotlib를 사용해 합성 데이터를 읽고 집계하고 시각화한다.
- AI: 특성·타깃·학습/평가 구분 및 Scikit-learn 의사결정나무 학습·예측·시뮬레이션을 이해한다.
- 실행: 함수와 조건으로 도구를 연결하고, 규칙 기반 자동화와 실제 생성형 AI 에이전트를 정확히 구별한다.
- 책임: 학생 개인정보를 입력하지 않고, 기계가 만든 출력의 검증 책임을 이해한다.

## B. 12차시 학습 경로(학생용 페이지의 내용과 1:1 연결)
| 차시 | 영역 | 핵심 Python/AI | 학생 산출물 | 지필평가 |
| --- | --- | --- | --- | --- |
| 1 | AI 에이전트 | 싱글·멀티, 목표/도구/검증 | 비서의 업무 흐름도 | 개념 구분 |
| 2 | 프롬프트 | 입력/출력/제약/완료 조건, dict | 5조건 요청서 | 논리·검증 |
| 3 | CSV/Pandas | read_csv, head, 열·행 선택 | 표 탐색 기록 | DataFrame |
| 4 | 분석 | groupby, mean, 조건 검색 | 취약과목 근거표 | 코드 결과 |
| 5 | 시각화 | matplotlib bar, 축·단위 | 과목별 평균 막대그래프 | 시각화 |
| 6 | 지도학습 | X/y, train_test_split | 특성·정답 분리 | 모델학습 |
| 7 | 의사결정나무 | DecisionTreeClassifier, fit/predict | 예측 실습 기록 | 함수 이해 |
| 8 | 시뮬레이션 | 입력값 변경·관찰 | 4개 조건 비교표 | 인과/상관 |
| 9 | 도구 구현 | def, return, if, 검증 | 도구 3개 연결 | 함수·실행순서 |
| 10 | 비서 엔진 | 문자열 분기/함수 호출 | 규칙 기반 비서 | 자동화 vs 에이전트 |
| 11 | 개인 프로젝트 | 명세·테스트·보고 | 가상 데이터 비서 | 검증·예외 |
| 12 | 종합/기말 | 출력 예측·문항 풀이 | 시연·성찰 | 종합 |

매 차시 고정 탭: ① 원리 이해 ② Python 실습(예제·편집·실제 실행 선택) ③ AI 실습(프롬프트·모의 도구 실행·체크) ④ 형성평가/기말 연습 ⑤ 교사용 공개 안내.
기본 시간 흐름: 도입 5분 → 핵심 설명 10분 → 실습 20분 → 적용 10분 → 정리 5분 (12차시 변형 가능).
차시 종료 기준: 실습 미션 3개 확인 + 객관식 응답 + 코드 출력 확인. 오답 피드백은 공개 연습 문제에 한정.
진도: localStorage 저장; 기기간 이동은 JSON 내보내기/가져오기. 익명 로컬 학습 진행이며 서버에 학생 식별정보를 저장하지 않는다.

## C. 실행 환경
- 기본: 학생 웹앱 → Python 코드 읽기·수정 → [이 브라우저에서 실제 실행] 버튼(선택) / Google Colab 또는 학교 PC의 로컬 Python.
- 브라우저 실행: 웹 워커에서 Pyodide 0.29.5 런타임을 필요할 때 CDN에서 내려받아 Python을 실행. Pandas, Matplotlib, Scikit-learn은 첫 실행 때 추가 다운로드가 필요하고 학교 네트워크 차단·메모리 부족 시 실패할 수 있다. 해당 경우 Colab/로컬 Python 사용.
- Python 예제는 차시마다 독립 실행 가능. 3~8차시는 동일한 18행 합성 CSV를 Python 문자열에서 DataFrame으로 생성하여 별도 파일 업로드가 없어도 동작한다.
- 실행 결과 중 JavaScript 차트는 '브라우저 계산 결과'로, 예상 출력은 '실행 전 예측'으로 명확하게 구분한다.
- Matplotlib SVG는 브라우저 실행 결과로 표시한다. 실제 기말시험 원안은 공개 웹앱에 포함하지 않는다.
- 권장: PC 29대, 화면 해상도 1280 이상, 학교 허용 Colab/IDE, 교사 화면 공유.

## D. 학생 학습 원칙
1. **코드 예상**: AI 코드를 먼저 실행하지 말고 예상 출력 적기.

5. **시험 연결**: 코드 함수·입력·출력을 기말 서술형에 적용.
6. **AI 안전**: 개인 실명·학교 내부자료·실제 성적·API 키 입력 금지.
