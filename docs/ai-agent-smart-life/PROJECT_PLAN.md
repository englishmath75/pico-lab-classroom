# AI AGENT SMART LIFE — 프로젝트 기획서
작성일: 2026-10-16
상태: 기획 및 개발 준비
대상: 고등학교 2학년 소프트웨어와 생활, 12차시

## 목적
교과서 데이터 분석·시뮬레이션·소프트웨어 개발 내용을 Python 및 AI 에이전트 실습과 연결한다. 기존 PICO LAB 수업과 평가 기능을 훼손하지 않는다.

## 공통 차시 구성
도입(흥미/영상) → 개념 설명 → Python 코드 실습 → AI 활용/검증 → 형성평가 → 진도 저장.
각 차시에는 학생용 학습지, 정답/해설, 교사용 지도안, 기말고사형 문항을 제공한다.

## 12차시
1. 생성형 AI와 AI 에이전트: 목표/도구/실행/검증
2. 프롬프트 설계와 AI 결과 검증: 입력/출력/오류
3. Python 변수·리스트·CSV
4. Pandas: DataFrame, 평균, 조건 검색, 정렬
5. Matplotlib: 그래프 생성과 해석
6. 머신러닝 원리: 학습/검증 데이터, 과적합
7. Scikit-learn: 의사결정나무 학습과 예측
8. 시뮬레이션: 입력 조건 변경과 결과 비교
9. Python 함수와 도구 호출: 에이전트 실행 루프
10. CSV 분석 도구를 연결한 학습 비서
11. 개인별 에이전트 완성·검증·발표
12. 코드 해석·오류 수정·기말 모의고사

## 구현 기능
- 학생용: 차시별 콘텐츠, 실습 코드, 실행/출력, 형성평가, 진도 표시, 복습
- 교사용: 차시 운영안, 정답 해설, 문항 관리, 진행 현황
- Python: CSV 예제, pandas/matplotlib/scikit-learn 실습, 실행 가능 환경의 명확한 구분
- 에이전트: 오프라인 도구 실행 모드 + 인증/비용 검토 후 생성형 AI 연결 옵션
- 기말고사: 코드 실행 결과, 빈칸, 오류 수정, 데이터/모델 해석 중심
- 연도별 재사용: 콘텐츠 버전과 학년도/학급/진도 데이터 분리

## 안전 및 운영
실제 학생 성적·개인정보를 외부 AI로 전송하지 않는다. 교사용 정답과 평가자료는 권한 분리한다. 학생 계정 가입을 강제하지 않는 실습 대안을 제공한다. AI 응답과 자동화는 검증 가능하게 만든다.

## 개발 절차
1. 기존 앱 구조 및 기능 조사
2. 화면 설계·차시 콘텐츠 원고
3. 학습/코드 실습 기능 개발
4. 에이전트 실습·기말 평가 기능 개발
5. 자동 테스트·교사용 검수
6. 기존 기능 회귀검증 후 승인된 배포

## 확인 필요
실제 교과서 판본/성취기준, 기말 범위, 차시당 수업 시간, 학교 AI 서비스 이용 정책. 확인 전에는 확정된 학교 평가계획이라고 표시하지 않는다.
