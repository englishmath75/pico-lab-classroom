# Arduino 수행평가 Tinkercad 최단·직관 배선 수정 작업 명세

> 작업 대상: 교사 계정에 저장한 3개 Tinkercad 회로. **실제 회로 편집·저장·시뮬레이션을 수행하는 작업 지시서**이며, 본 문서 자체가 회로 수정을 의미하지 않습니다.

## 목표
직각으로 길게 우회한 선을 **가장 가까운 전기적으로 올바른 연결점에 짧게 연결**한다. 수업을 처음 듣는 학생이 시작 핀, 도착점, 기능을 시각적으로 즉시 이해하도록 한다. **짧고 직관적인 배선 > 무조건 직각 배선**. 필요할 때만 1~2번 꺾는다.

### 편집할 실제 회로

1. **STEP 1 초음파 + 부저** — https://www.tinkercad.com/things/h4ANNRDybN4-newstep1/editel
2. **STEP 2 CDS + 가변저항 + 빨강/초록 LED** — https://www.tinkercad.com/things/icXpmxWfLZp-newstep2led/editel
3. **STEP 3 전체 통합** — https://www.tinkercad.com/things/7DmFxG3ZbXv-newstep3/editel

모든 링크는 교사 소유 비공개 회로일 수 있으므로 로그인 세션에서 연다. 기존 회로는 임의 삭제하지 않는다.

## 최우선 조건: 현재 **정상 작동 코드 그대로 유지**

현재 검수된 최종보고서에 있는 저장 코드와 핀 번호를 변경하지 않는다. 코드에 새로운 변수·함수·주석을 덧붙이지 않는다. 전자적으로 동일한 노드로 선을 옮기는 것만 허용한다. 필요하면 부품과 브레드보드의 위치만 변경한다.

| 부분 | Arduino Uno 연결 |
|---|---|
| HC-SR04 TRIG/ECHO | D7/D8 |
| 부저 신호/GND | D2/GND |
| CDS 분압 접점 | A0 |
| 10kΩ 가변저항 가운데(와이퍼) | A1 |
| **빨강 LED** | D9, 독립 |
| **초록 LED** | D10(PWM), 독립 |
| 각 LED | 개별 330Ω 직렬 저항(현 저장 회로 저항값 유지) |
| 전원/접지 | 5V/GND, 브레드보드 전원 레일 공통 |
| 시리얼 | 9600 bps |

현재 실제 코드의 기능: 거리 <20cm → D2 부저 켜짐; CDS<400 → D9 빨간 LED 켜짐; 가변저항 0~1023 → 초록 LED D10 PWM 0~255. 세 출력 서로 독립.

## 배선이 길어진 이유와 방지 기준

현재 STEP 2·STEP 3 스크린샷에는 우측 바깥쪽과 상·하단 바깥을 큰 사각형으로 돌아오는 초록색 신호선이 있음. 이는 전기적으로 맞더라도 학습자가 연결을 추적하기 어렵다.

수정 시 아래 순서로 진행:

1. 작업 전 회로 전체 캡처하고, **Tinkercad 내부에 백업 복사본**을 저장할 수 있으면 먼저 저장한다. 원래 회로·코드 보존.
2. Uno와 브레드보드를 가까이 배치. 두 브레드보드면 위아래 간격도 적당히 좁힘. 부품이 겹치거나 핀이 가려지지 않도록.
3. 우회선 **1개씩만** 제거 → 출발 핀을 확인 → 도착 부품이 속한 **동일 전기적 노드**의 가까운 브레드보드 구멍으로 짧게 재연결. 
4. 신호선은 Uno 옆면에서 보드의 **가까운 측면 구멍**으로, 필요한 경우 1~2개의 작은 꺾임 사용. 보드 위·아래·우측 외곽을 크게 한 바퀴 도는 선 금지.
5. 전원 5V 빨강, GND 검정, 신호 기능별 색상 구분. **모든 신호를 무조건 초록색으로 통일하지 않음**(예: 초음파 신호 파랑/청록, CDS 보라, 가변저항 초록, LED 각각 해당 색 계열 등). 극성 혼동 주의.
6. **기존 실물 배선과 전기적 동일성을 확인**: 브레드보드 a-e / f-j는 중앙 홈을 건너지 않으며, 레일 단절 구간도 건너뛰어 연결하지 않음. LED 직렬 저항은 우회하지 않음.
7. 5V/GND 단락이 없는지 검토하고 **매 선 수정 후 시뮬레이션**. 마지막에 기능별 입력 조작 검사.
8. 선 길이를 줄일 수 없다면 선을 큰 사각형으로 재배선하지 말고, **부품 위치·방향 또는 브레드보드 위치를 먼저 바꾸는 방안**을 검토한다.

## STEP별 도선 수정 및 동작 검증

### STEP 1 — HC-SR04 + 부저
- HC-SR04 신호선 TRIG D7/ECHO D8을 센서에 가장 가까운 구멍으로 연결. VCC/GND도 가까운 레일을 사용. 부저 D2는 보드 내 가까운 부저 단자로.
- 15cm 근처: 부저 작동. 35cm 근처: 부저 정지. 시리얼 거리값 변화.
- **STEP 1 코드는 변경 금지**.

### STEP 2 — CDS·가변저항·빨강/초록 LED
- **우측 외곽을 도는 긴 녹색 선부터** 제거하고 A0/A1/D9/D10과 해당 부품 노드를 가장 가까운 전기적 동등 구멍으로 재연결.
- 빨강 D9→(330Ω LED 직렬)→GND, 초록 D10→(330Ω LED 직렬)→GND. LED 출력 기능이 서로 뒤바뀌지 않도록 실물/코드 대조.
- 조도 CDS 54(어둠) → 빨강 켜짐, 974(밝음) → 빨강 꺼짐. 가변저항 0→초록 PWM 0, 1023→초록 PWM 255. 조도 변화만으로 초록 밝기 변하면 오류.
- **STEP 2 코드는 변경 금지**.

### STEP 3 — 전체 통합
- 부저, HC-SR04는 위 보드에 둘 수 있고, 두 LED·CDS·가변저항은 원래 의도된 보드에서 유지하거나 보기 쉽게 재배치. 두 브레드보드는 맞닿지 않되 가깝게.
- 상단 디지털 D2/D7/D8 신호는 가능한 한 바로 인접한 센서/부저 노드로. D9/D10 LED 신호와 A0/A1 입력은 Uno↔해당 보드 사이 **짧은 중앙 경로**를 이용. 보드 바깥 대형 우회 루프 제거.
- 거리 근/원(약16cm/40cm) × CDS 어두움/밝음(54/974) × pot 0/1023 총 **8조건** 테스트. 빨강·초록·부저는 각자 해당 입력에만 반응.
- **STEP 3 코드는 변경 금지**.

## 완료 조건

- [ ] 각 회로 전체 캡처로 배선 경로를 눈으로 확인 가능

- [ ] 기존 코드 및 핀 번호 변경 없음(수정 전·후 비교)
- [ ] STEP 1·2·3 시뮬레이션 기능 시험 통과 (STEP3 8조건)
