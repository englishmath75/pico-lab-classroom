# DATA DETECTIVE 수업 내용 동결 및 보충 운영 규칙

적용 범위: 고2 「소프트웨어와 생활」 / 3단원 현상을 분석하는 소프트웨어

## 1. 수업 후 동결
- 교사가 실제로 수업한 페이지는 해당 시점의 **본문, 예제 코드, 문제, 정답, 학습 순서**를 보존한다.
- 수업이 끝난 뒤 내용 개선을 이유로 기존 부분을 직접 고쳐서 학생의 학습 기록과 시험 학습 기준이 바뀌게 하지 않는다.
- 학습 진행이 필요하여 링크를 추가하는 경우에도 수업 본문을 덮어쓰지 않는다.
- 보안 문제, 심각한 오류, 개인정보 위험 등 예외가 있으면 교사에게 변경 사유와 범위를 설명하고 필요한 승인을 받은 뒤 진행한다.

## 2. 질문 보충 페이지
- 앞으로 새 질문·이해 심화·오류 해결·추가 형성평가는 `public/pandas-data-lab/questions-supplement.html`에 추가한다.
- 원본 수업 페이지와 독립적으로 작성하고, **날짜·주제·관련 강의·코드·정답**을 남긴다.
- 원본에 오류가 발견되면 보충 페이지에 "**정정 및 이유**"를 기록하고 어떤 내용을 바르게 이해해야 하는지 명시한다.
- 이미 공개한 보충 항목도 원칙적으로 덮어쓰지 않고 새 항목이나 정정 이력으로 변경 이유를 보존한다.

## 3. 시험 출제 기준
- 출제 범위는 학교의 평가계획과 수업 시간에 실제 안내·학습한 내용이 기준이다.
- 수업 이전 추가한 필수 항목과 수업 이후 선택 보충 항목은 혼동하지 않도록 교사가 출제 대상 여부를 명시한다.
- 고급 그래픽 작품 체험실 등 기존에 "시험범위 제외"로 표시한 영역은 별도 고지 없이 포함하지 않는다.

## 4. 소스와 배포
- 원본 코드 저장소: `englishmath75/pico-lab-classroom`
- 최종 수업 사이트: `https://englishmath75.github.io/sw/` (사용자 지정 도메인 `https://sw.englishmath.kr/`)
- 배포 저장소 `englishmath75/sw`는 원본을 주기적으로 가져와 게시하므로, 학생 자료 수정은 원본 저장소 기준으로 처리한다.
- 모든 변경은 Git 커밋으로 이력을 남기고, 원본 배포와 /sw/ 게시를 별도로 검증한다.
