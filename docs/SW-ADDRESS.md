# 공식 학생용 주소

- 데이터 분석 교실 메인: https://englishmath75.github.io/sw/
- 차시별 실습: https://englishmath75.github.io/sw/step-by-step.html?lesson=1
- 전체체험: https://englishmath75.github.io/sw/first-analysis.html
- 기존 아두이노·피코 교실: https://englishmath75.github.io/sw/pico.html

이 저장소는 수업 콘텐츠의 원본과 Git 이력을 계속 관리합니다. 소스 파일은 기존 `public/pandas-data-lab` 위치에서 수정하세요.
별도 `englishmath75/sw` 저장소의 배포 작업이 이 저장소의 특정 main 커밋을 가져와 `/sw/`로 빌드·게시합니다.
영상·CSV·Python 코드도 함께 게시합니다. 웹 주소만 변경하며 학습 기록의 localStorage 키를 바꾸지 않습니다.

SW 배포는 해당 저장소의 push·수동 실행 및 15분 간격 원본 변경 확인으로 실행됩니다. 예약은 GitHub 상황에 따라 지연될 수 있습니다.
급히 수업 자료를 게시할 때는 SW 저장소의 `SW classroom publish`도 수동 실행하고 `site-version.json`의 source_sha를 확인하세요.
이 저장소의 기존 주소는 배포 시 이동 스크립트를 넣어 새 경로로 안내합니다. 대상이 아직 없거나 접속 오류이면 기존 페이지를 유지합니다.
쿼리(`lesson`, `page`, `view`)와 앵커는 보존합니다. 새 사이트가 확인되기 전 기존 Pages를 끄거나 저장소를 삭제하지 마세요.
