# 영상 연결 코드의 현재 상태

학생 화면에서 영상 목록은 비어 있으므로 영상 플레이어는 나타나지 않는다. 2차시 보충 코드·표·CSV만 이용할 수 있다. 기존 차시·실습·문제·저장 기능은 유지한다.

실제 완성 영상이 검증된 뒤 lesson-videos.json의 lessons 배열에 다음 속성을 등록한다: lesson(정수 1~10), status(verified), src(같은 경로의 실제 MP4), captions(실제 한국어 VTT), duration(실제 길이의 초), chapters([{at: 실제 초, title: 한국어 구간명}]). 존재하지 않는 샘플 URL은 등록하지 않는다.

플레이어는 영상과 자막의 HTTP 응답을 먼저 확인한다. 재생·일시정지·자막·전체 화면은 브라우저 기본 controls, 배속과 구간 이동은 추가 컨트롤을 사용한다. 연결 후에는 별도로 실제 재생·탐색·자막 싱크·모바일 가독성을 검증해야 한다. HTTP 성공은 재생 성공을 보장하지 않는다.

이번 단계는 완성 영상이 없는 구현 초안이다. 영상은 0개이며, MP4·음성·자막·호스팅·배포 후 재생은 미완료다. 실제 녹화·음성 제작 수단이 확인된 다음 2차시 품질 검수를 통과해야 나머지 차시 제작을 확장한다.
