# 2차시 영상 통합

Arduino learning-videos/player.js와 player.css, hls.min.js를 재사용하여 같은 사이트의 video-player.html에서 HLS를 재생한다. 2차시 실습 화면에 플레이어를 삽입하고 22개 구간, 배속, 재생 위치 저장, CC 자막을 제공한다. 기존 Arduino 페이지의 코드는 변경하지 않는다.

MP4 원본은 H.264/AAC/선택형 mov_text 자막, 1920×1080, 30fps다. 웹 배포는 같은 영상·음성 스트림을 20초 단위 HLS로 분할하고 VTT 자막을 제공한다. 실제 렌더 길이는 1109.8초(18분 29.8초)다. 전체 대본과 실제 장면 시간은 videos/lesson02/transcript.md와 timeline.json에 기록했다.

화면은 학습용 재현이며 실제 화면 녹화가 아니라고 영상과 플레이어에 표시했다. Python 출력은 실제 실행으로 확인했고 VS Code 자체에서 촬영·실행한 증거로 표시하지 않는다. 음성은 기본 한국어 합성 음성이고 교사 목소리를 복제하지 않았다.

0·1·3~12차시 영상은 아직 목록에 없으므로 재생 버튼도 표시하지 않는다. 나머지 강의를 완성한 것으로 보고하지 않는다.
