## 순회 지도·오류 해결

- join의 따옴표 사이 공백 한 칸을 확인한다. 문장이 경계에서 붙지 않도록 한다.
- split 뒤의 ()와 value_counts의 복수형 s 및 ()를 확인한다.
- 문장 리스트 길이 3, 단어 Series 길이 6, 빈도표 길이 3을 구별시킨다.
- 반복 문장은 이 예제에서는 의도된 입력이다. 실제 수집 자료에서는 수집 중복과 원문의 반복을 구별한다.
- 한국어 공백 분리 결과를 정교한 형태소 분석으로 부르지 않는다.
- 기본 세 단계까지만 마쳐도 핵심 학습을 완료한다. 표 결합 4~5단계는 선택 심화다.

## 보충·심화

- 느린 학생: join, split, Series, value_counts를 별도 변수로 나누고 중간 결과를 출력한다.
- 빠른 학생: 소문자 변환·쉼표 정리 전후 빈도와 적용 이유를 기록한다.
- 선택 심화: right 순서 변경 시에도 key 대응이 유지됨을 확인한다. right에 A만 남기면 기본 inner 결합 결과는 A 1행이다.
- 결합 이후 행 수와 키의 대응을 확인한다. key가 중복되는 다른 상황까지 항상 2행으로 일반화하지 않는다.

## 형성평가 정답·해설

1. climate는 3회. 문장마다 한 번씩 등장한다.
2. 전체 단어 값 6개, 서로 다른 값 3종류. 3+2+1=6이다.
3. split은 공백 분리다. 대소문자·문장부호 정리는 따로 정한다.
4. 빈도만으로 글의 의도를 확정할 수 없다. 문맥과 사용 방식을 살핀다.
- 기존 웹앱 두 문항 정답: 3 / 아니요.
