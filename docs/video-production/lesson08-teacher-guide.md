## 순회 지도·보충

- 코드 입력: import 별칭, 괄호·따옴표·쉼표, DataFrame의 두 목록 길이 4를 확인한다.
- 원래 기온: 13.1, 13.4, 13.0, 13.8. 최고 2024, 최저 2023. 마지막−첫 값은 약 0.7도, 매년 상승은 아니다.
- 느린 학생: 표의 각 행을 좌표로 짝지어 적고 기존 5단계를 한 줄씩 누적한다. CSV 확장은 기본 완성 후 선택한다.
- 값 변경: 13.8→12.8이면 최고 2022년13.4, 최저 2024년12.8. 이후 원래 값 복원.
- 오류: 없는 Temp 열은 KeyError, x4개/y3개는 ValueError. 길이만 임의로 맞추기보다 같은 행 선택을 확인한다.
- 웹 결과에 print가 없어도 그래프는 나타난다. 최초 도구 준비 시간을 기다리고 결과 영역 확인.
- VS Code: 같은 인터프리터에 pandas/matplotlib 설치, 기본은 CSV 불필요. 확장은 같은 폴더에서 실행.
- 그림 저장은 plot·레이블·제목 뒤, show 앞. 실제 PNG를 열어 빈 그림이 아닌지 확인한다.

## 빠른 학생 심화

- ylim(0,20)과 자동 범위를 비교하고 수치는 같지만 그림의 인상이 달라지는 이유를 설명한다.
- 봄 CSV: season 조건 → year 정렬 → temp_c 시각화. 2020~2024년12.6→14.1, 차이1.5도.
- 봄과 여름을 각각 선택해 두 선으로 비교하되 범례·제목을 추가하고 원자료를 보존한다.
- 네 개의 가상 값이나 다섯 개의 가상 봄 값으로 실제 장기 기후의 원인을 입증하지 않는다.
