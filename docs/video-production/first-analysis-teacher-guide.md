## 순회 지도·보충

- 모든 코드를 직접 입력하되, 페이지의 6개 단계를 순서대로 누적한다. 영상의 중간 확인용 print는 원본 분석 결과를 바꾸지 않는다.
- ZIP 안에서 바로 실행하지 않는다. Python 인터프리터와 설치 환경을 맞춘다.
- 늦은 학생은 1~3단계 12건 확인까지 먼저 완성한 뒤 교사와 4~6단계로 연결한다. 함수 암기보다 각 단계 역할을 말하게 한다.
- quantity 결측 O013·O014와 음수 O015를 구별한다. 제외한 값은 0으로 임의 대체하지 않는다.
- summary의 메뉴명 인덱스는 저장할 때 포함한다. 원본은 덮어쓰지 않는다.

## 자주 틀리는 부분

- 파일 이름 뒤 (1), 압축 내부 실행, 다른 폴더의 CSV, __file__을 대화형 창에서 실행하는 경우.
- unit_price 쉼표 제거 전 숫자 변환, 양수 조건 괄호·& 누락, 열 이름 철자.
- matplotlib 그래프 창이 열린 동안 실행 종료를 기다리는 경우. PNG 저장 후 창을 닫는다.

## 정답·해설

- 정제 후 12건, 중복 제거 1건, 분석 제외 3건, 수량 결측 2건.
- 와플 8개·36000원 / 떡볶이 10개·35000원 / 레몬에이드 12개·30000원. 총 30개·101000원.
- 판매량 1위 레몬에이드, 매출 1위 와플. 단가가 달라 순위가 다르다.
- 비용 자료가 없어 이익 1위는 알 수 없다. 제외 자료의 올바른 수량도 모르므로 원본 전체 주문의 확정 매출이 아니다.
