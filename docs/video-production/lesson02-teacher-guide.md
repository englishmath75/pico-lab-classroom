# 2차시 · 50분 수업 운영안

상태: 영상 제작 전 운영안. 아래 구간은 대본의 목표 시간이며 실제 재생 가능한 MP4 구간이 아니다. 완성 영상의 실측 시간으로 다시 맞춘다. 학생용 HTML에서 이 문서를 연결하지 않는다. 실제 학생 기록·성적·학교 시험 문항은 포함하지 않는다.

| 수업 경과 | 활동 | 목표 영상 구간 | 순회 지도 확인 |
|---|---|---|---|
| 0~4분 | 접속·이전 시간 확인 | 재생 전 | 2차시 열기, 입력·실행 버튼 위치 |
| 4~9분 | 목표·행·열·인덱스 | 00:00~02:30 | 인덱스를 데이터 열로 세는지 |
| 9~18분 | 독서량 표 직접 입력 | 02:30~05:40에서 정지 | name/books의 리스트 길이, 쉼표·따옴표 |
| 18~25분 | 열 선택·평균·값 수정 | 05:40~08:30에서 정지 | mean() 괄호, 10/3과 12/3의 차이 |
| 25~33분 | 점수 예제·오류 해결 | 08:30~11:15에서 정지 | 80.0 → 250/3, KeyError 원인 |
| 33~38분 | CSV·코드 저장 | 11:15~12:05에서 정지 | CSV를 읽은 코드로 오해하지 않는지 |
| 38~45분 | 확인 문제·해설 | 12:05~14:20에서 정지 | 먼저 답한 후 정답 확인 |
| 45~50분 | 오류 기록·백업·정리 | 14:20~16:00 | .py 저장과 JSON 백업을 구분하는지 |

빠른 학생: books에 값을 하나 더 추가하고 name에도 같은 개수의 이름을 추가해 평균과 shape를 확인한다. 인덱스를 1부터 시작하도록 `df.index = range(1, len(df)+1)`을 적용하고 평균이 유지되는지 설명한다. 평균이 같은 서로 다른 세 값의 예를 구성한다.

보충 설명: 중괄호는 자료 전체, 대괄호는 한 열에 들어갈 값 목록이다. 먼저 두 열의 세 값이 나란히 대응하는 것을 손가락으로 짚게 한다. pd와 df를 서로 혼동하면 pd는 도구의 별칭이고 df는 만든 표의 변수라고 역할을 구분한다. 코드를 대신 완성해 주기 전에 마지막 오류 줄을 함께 읽는다.

자주 틀리는 코드와 해결:
- `Dataframe`: `DataFrame`의 대문자 D·F 확인.
- `df['Books']`: 실제 열 이름 `books`와 대소문자 일치.
- `df['books'].mean`: `()`를 붙여 평균 계산 실행.
- `books` 값을 문자열로 입력: 학습 예제의 3·5·2에는 따옴표를 붙이지 않음.
- 두 리스트 길이가 다름: 한 사람당 모든 열의 값이 하나씩 있어야 함.

확인 문제 정답: 독서량 표 (3, 2), `print(df['books'].mean())`, 인덱스 변경만으로 평균과 크기는 변하지 않음. 기존 2차시 문제의 정답은 Series와 1500.0이다.
