## 순회 지도·오류 해결

- 기본 자료: item juice/bread/milk, sales12/30/18. 3행2열. 원본 다운로드 lesson_10.py와 영상 기본 코드 AST가 같다.
- 내림차순 정렬 결과 bread30,milk18,juice12. 인덱스1,2,0은 원래 행 이름. 재대입하지 않은 df는 입력 순서 유지.
- 평균은 세 상품 대상20.0개, 최댓값30개. 학생당 평균이나 하루 평균으로 부르지 않는다.
- juice12→42 변경 시 평균30,최대42,juice1위. 뒤의 기본 보고서는 원래12로 복원해 사용.
- Sales 열 오타는 KeyError, 정상 sales. mean()/max() 괄호 확인.
- 기본 막대그래프의 x상품,y판매량(개). 원인이나 실제 연간 추세는 이 가상 하루 자료로 확정할 수 없다.

## 보고서 작성 지도

- 7개 항목: 탐구 질문 / 자료 출처·수집 기간·단위 / 결측 처리와 Pandas 분석 과정 / 분석 결과·근거 수치 / 그래프 유형·축·해석 / 표본 편향·윤리·인과관계의 한계 / 후속 탐구와 해결 제안.
- 실제 하지 않은 전처리, 실제 조사하지 않은 출처를 쓰지 않는다. 기초 데이터에는 결측이 없다.
- 자료 범위는 가상 하루·세 상품. 실제 수집 날짜는 주어지지 않았다.
- HTML 보고서에는 작성한 텍스트가 저장된다. PNG는 별도 파일로 같은 폴더에 보관한다. 존재하지 않는 업로드·자동 제출 기능을 안내하지 않는다.
- 자동 저장은 현재 브라우저 저장, HTML은 읽을 보고서, JSON은 기록 복원용. 코드와 원자료, 그림도 함께 보관.
- 개인정보 없이 가상 예제로 설명한다. 저장은 자동 제출을 뜻하지 않는다.

## 보충·심화

- 느린 학생: 기본 표·정렬·평균·최대를 끝내고 두 문장 결론과 한계 한 문장을 먼저 쓴다. CSV는 선택 확장.
- 빠른 학생: CSV의 상품별 합계·평균·매출을 비교하되 기준과 단위를 설명하고 비의 인과효과를 단정하지 않는다.
- CSV 10행5열. 결측 칸0, 완전 중복행0. 불필요한 채움·중복 제거를 했다고 꾸며 쓰지 않는다.
- menu별 sold합계 김밥131개/주스86개, revenue합계458500원/172000원. 전체217개/630500원. 매출과 이익 구별.
- sold전체10행 평균21.7개, 상품별5요일 평균 김밥26.2개/주스17.2개. 기본 평균20과 섞지 않는다.
- day/rain별 하루 총 판매량으로 비교: rain0은3일평균50개, rain1은2일평균33.5개. 관측 일수가 다르고 다른 조건이 있으므로 원인 확정 불가.
